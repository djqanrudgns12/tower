최신 결정: 41번 화풍 선택. 동일한 맵에서도 웨이브마다 배경 분위기를 조금씩 바꾼다. 5/10/15/20… 웨이브는 강한 적과 더 큰 보상을 체감하는 고비로 만든다. 정확한 보상·배율·무드표는 후속 밸런스 검증 대상이다.

한글·훈민정음·세종대왕 소재는 일부 **고정 장식**에만 적용한다. 전투 기물과 몬스터 전체의 테마가 아니다. 하단 문제·우측 기물 관리·격자 중심 배치·긴 경로·실제 발사와 피격·가벼운 보행을 유지한다.

현재 단계는 문서 정리/이관이다. **새로운 구현 지시 전에는 앱 생성, 패키지 설치, 에셋 대량 제작, DB 생성이나 배포를 하지 않는다.** 이전 시안 코드와 검사 자료는 `docs/archive/`에 보관했으며 이미지 삭제로 더 이상 실행용이 아니다.

## 다른 컴퓨터에서 받기

```sh
git clone https://github.com/djqanrudgns12/tower.git
cd tower
```

문서와 PNG 확인에는 패키지 설치가 필요 없다. 문서 생성·과거 구조 검산만 실행하려면 Node.js를 사용한다.

```sh
node tools/build-plan.mjs
node tools/validate-plan.mjs
```

위 검사는 제품 테스트나 최신 긴 경로 맵 검증이 아니다. Node/프레임워크 버전은 구현 착수 시 공식 자료를 확인하고 정확한 버전으로 잠근다. 이 저장소에는 아직 제품 `package.json`/lockfile이 없다.
