# Argon·Codex·Claude 공동검수 절차

2026-10-27 사용자 결정 반영. 사용자는 베타테스트를 맡고, 문항 제작·내용 검토는 AI 세 주체가 수행한다. 원문의 교사 승인 필수 조건을 대체하며 `joint_review_approved`라는 상태를 사용한다. 교사 검수·교육기관 인증·오류 없음으로 홍보하지 않는다.

## 역할

| 담당 | 주 책임 | 별도 검토 결과 |
|---|---|---|
| Argon | 공식 근거에 따른 초안, 모든 보기 대입, 자체 반박, 반려 재작성 | 원본·근거 연결·오답 이유·자체 점검 |
| Codex | 스키마/출처/의미ID 실제 확인, 정답 키/유일성/중복 검사, 수합 | 기계 검사 + 근거 검증 + 독립 정답 판단 |
| Claude | 정답 키를 보기 전 독립 풀이, 모든 보기 반박, 문맥/학년/문장 적합성 | 독립 선택·복수답 가능성·이유·수정 권고 |
| 사용자 | 실제 플레이·읽기·학년 체감·이상 문항 베타테스트 | 불편/혼동/오류 제보, 공개 판단 |

이는 관심 영역의 분담이지 나머지 항목을 검토하지 말라는 뜻이 아니다. 세 주체 모두 최종 revision의 정확성/유일답/학년/해설을 판정한다. Argon의 생성 직후 자체 점검은 Claude 또는 Codex의 독립 검토를 대신하지 않는다.

## 작업 순서

1. 실제 사전 근거와 학년 선정 근거를 먼저 확보한다. 세 AI가 같은 잘못된 전제를 공유하지 않도록 URL뿐 아니라 해당 의미의 근거 스냅샷과 hash를 제공한다.
2. Argon은20문항 소배치로 draft와 자체 반박을 제출한다. 공동검수 승인을 직접 부여하지 않는다.
3. Codex와 Claude의 첫 풀이에는 생성자의 정답/해설/다른 검수자의 결론을 숨긴다. 지문/보기/학년으로 각각 정답 또는 ‘복수답/정답없음/근거부족’을 고른다.
4. 두 독립 선택을 기록한 뒤 정답 키·근거·해설을 공개하여 대조한다. 사전 사실 확인, 4개 보기의 문맥 적합성, 학년 선정 근거를 따로 체크한다.
5. 모든 주체가 `pass`이고 기계 검사 통과·출처 일치·정답 일치·미해결 지적0이면 Codex가 해당 hash를 `joint_review_approved`로 등록한다. 숫자 자신감 평균이나2대1 다수결로 통과시키지 않는다.
6. `fail/uncertain`이 하나라도 있으면 quarantine. Argon이 수정하여 revision을 올리고 변경된 문항 전체를 다시 검토한다. 반복2회 뒤에도 해결되지 않으면 해당 문항은 제외하고 다른 어휘로 대체한다.
7. 사용자 비공개 베타테스트 후 공개 후보를 구성한다. 사용자가 모든 문항을 한 번씩 직접 읽어야 한다는 요구는 추가하지 않는다. 베타테스트가 전 문항 전문 검수를 대신했다고 기록하지도 않는다.
8. 배포 후 오류 신고가 확인되면 철회 오버레이로 차단하고 정정 해설을 공동검수한다. 이전 점수를 조용히 다시 계산하지 않는다.

## 보고서 계약

각 보고서: `reviewId`, `reviewer`(argon/codex/claude), `modelOrTool`(실제 사용한 값), `executedAt`, `questionId`, `revision`, `contentHash`, `blindChoice`, `sourceVerdict`, `uniquenessVerdict`, `gradeVerdict`, `languageVerdict`, `explanationVerdict`, `overallVerdict`, `findings[]`, `evidenceRefs[]`. 각 verdict는 pass/fail/uncertain. 학년 적합성을 사전 등급만으로 자동 통과시키지 않는다.

실제 호출·결과가 없는 주체의 보고서를 Codex가 대신 만들어 채우지 않는다. 현재 대화에서 Gemini/Claude 연결이나 실행은 확인하지 않았다. 연결 가능한 도구가 생기면 사용하고, 그렇지 않으면 Codex가 검토용 묶음과 요청문을 만들어 사용자가 전달한 실제 결과를 수합한다. 연결 전에는 검토 예정으로 표시한다.

## Claude 전달 요청

> 제공한 batch의 문항을 독립 검토해 주세요. 먼저 정답 키와 다른 검수 의견 없이 각 문항의 답을 고르고, 정답 없음/복수 정답/불확실을 허용하세요. 이후 제공되는 사전 의미 근거와 해설을 대조하여 모든 보기를 반박하고 학년 선정 근거·한국어 자연스러움·해설의 타당성을 별도 판정하세요. 지정 보고서 필드로 실제 검토한 revision/hash만 제출하세요. 근거 없는 의미 ID나 실행하지 않은 도구 결과를 만들지 말고, 하나라도 해소되지 않은 의문이 있으면 uncertain으로 남겨 주세요.

## 기록상의 한계

세 AI의 합의에도 동일한 자료 오류와 판단 편향이 남을 수 있다. 이 한계 때문에 사용자에게 모든 검수를 떠넘기거나 추가 교사를 필수로 요구하지 않는다. 대신 실제 근거 확인, 독립 풀이, 불일치 보류, 작은 배치, 사용자 베타테스트, 빠른 철회를 함께 운영한다.
