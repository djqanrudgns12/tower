# PRD 보강 검토 기록

2026-10-28 · 작성: 현재 Codex 세션. 외부 Opus/Argon 독립 검토가 반환된 문서가 아니다.

## 판단

기존 문서는 전투 판정·경제·저장·오답 정책의 기초가 좋다. 전체를 새 게임으로 바꾸는 것보다, 남은 제품 결정을 닫고 충돌하는 자료의 적용 순서를 없애는 편이 효율적이다. 화면의 크기/밀도와 작은 칸의 조작, 생성 아트의 실제 반려 기준, 작업자 간 소유권과 인계를 보강해야 구현 결과의 편차를 줄일 수 있다.

`design-41-kingdom-expedition.png`는 실제로 열어 확인했다. 위쪽 전장·큰 우측 장비함·하단 문제판, 목재/청동 테두리, 밝은 자연물, 궁수/포/마법사, 문화 장식의 일부 사용이 기준이다. 원화의 우측 패널 약1/4·하단 약1/3을 그대로 따라가면 과도한 UI 크기가 될 수 있어 **화풍을 보존하면서 UI 치수는 별도로 정했다.** 이 판단은 구현된 게임의 사용성 실측이 아니다.

## 검토한 입력

- 원문 v0.1, 통합 v0.3, additions/decisions, README/HANDOFF/READ_FIRST.
- v0.2 상세 구현 계획·미술/문항 계약·공동검수 절차·위험 검토·완료 점검.
- 과거 맵/문항 스키마와 문서 생성·검산 도구.
- 보존된 41번 원화. 삭제된 다른 시안은 재생성하지 않았다.
- 현재 사용자의 모델 환경·병렬 작업·총괄 교대·Codex 이미지 제작 지시.

과거 문서의 작성자 표시만으로 그 작업이 실제 서브에이전트 또는 외부 Claude의 독립 검수였다고 인증하지 않는다. 이번 판단은 현재 저장소에 존재하는 산출물 내용에 대한 검토다.

## 더 나은 대안으로 채택한 것

1. 원화의 장식을 전부 구현하기보다 미술 언어와 정보 위계를 분리한다. 프레임을 얇게 줄이고 실제 전투/문항의 마감을 먼저 완성한다.
2. 30종·4맵·3,200문항 동시 제작 대신 G1/G2로 규격을 입증한 뒤 확대한다. 전체 출시 범위는 유지한다.
3. 모든 변경의 세 모델 순차 검토 대신 일반 UI는 자체확인+총괄 인수, 위험한 핵심만 별도 검수한다. 문항의 기존3주체 공동검수는 배치 파일로 유지한다.
4. 주 총괄을 무조건 Codex로 고정하거나 모델끼리 지속 대화시키지 않는다. Codex↔Claude가 실제 작업 상태를 인계하고 Argon의 독립 묶음은 교대 중에도 이어간다.
