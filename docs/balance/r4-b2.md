## 2. 필드 정의(화면·B3가 쓰는 계약)

- **`towers.<id>.strongVs` / `weakVs`**: 상성 표지(`FoeTag`) 목록. 형태(`forms.<id>.<A|B|A1…>`)에 적으면 그 형태부터 바뀌고, 2차형은 1차형 값을 물려받는다. 읽는 함수는 `matchupOf(b, type, form)`(`src/domain/towers.ts`).
- **`matchup`**: `{ strongBP: 13000, weakBP: 7000 }`. 직접 타격(투사체·즉발·튐·파편·장판·덫·굴림)의 피해에, 적의 표지가 strongVs에 있으면 ×1.3, weakVs에 있으면 ×0.7을 표지마다 한 번 곱한다(내림, 상황 배율: 정예·대장 → 비행 → **상성** → 빈사 → 감속 중). 화상(지속 피해)에는 곱하지 않는다. 쏜 순간의 형태를 투사체에 `towerForm`으로 싣는다.
- **적의 표지**(`foeTags`): 역할(분열 조각은 `splitter`) + 정예면 `elite`. 종족 특성(`clay`·`burrow`)은 B3에서 적에게 붙인다.
- **대공이 안 되는 타워**는 weakVs에 `flyer`를 적는다(구조 약점, 시험이 지킨다). 궁수는 기준이라 둘 다 비어 있고, 깃발은 공격하지 않아 비어 있다.
- **징집 대응 보장**은 기본형 strongVs를 읽는다(`countersOf(b, tag)`). B1의 임시 `draft.counters`는 지웠다.

## 4. 미달 줄과 이유·대안(사용자 결정)

1. **정답률 효과 3.6·사망 폭 3**(B1 4.0·3과 같은 수준). B1 보고의 가설("강화 효율을 올리면 오른다")은 **틀렸다**: 효율 0.81에서도, 0.88에서도 3.5 안팎이다. 후반 힘이 골드에 비례해도 골드 자체가 정답률 1.5배 차이밖에 안 나기 때문이다(봇의 읽기 시간은 정답률과 무관하게 12초로 같다).
   - 대안 A: **불꽃 중 처치 골드 ×2**(처치 수입을 정답 연속에 묶음). 예상: 정답률 95%의 수입이 60%의 1.5배 → 1.65배 안팎, 효과 +0.7~1웨이브. 처치 연출(+골드)은 남는다.
   - 대안 B: 관문 봇의 읽기 시간을 정답률에 연동(95%는 빠르게)해 다시 잰다(tools/sim, 측정 정의 변경). 실제 학생은 잘 알수록 빨리 푼다.
2. **최적화형 95% 15.6·전략 효과 0.8·초보60→최적95 5.3**: 최적화형이 균형형보다 낮다(95%에서 15.6 대 17.1, 80%에서 14.2 대 16.0). 2웨이브 앞만 보는 롤아웃이 키우기 판에서 오히려 손해다(장비 한계, tools/sim). 대안: 롤아웃을 3~4웨이브로 늘리거나 "다음 진화까지 모으기"를 후보에 넣는다(B0 담당) / 목표를 "최적화형 ≥ 균형형 + n"으로 다시 정의.
3. **가장 좋은 단일 타워(통나무 15.1) ≤ 균형형 − 3, 단일 판 ≥W6(서리 4.5·바람 0)**: 지상 전용 타워 단일 판이 강한 까닭은 비행 적(10~15%)이 새도 1씩만 깎여 전회복으로 버티기 때문이다. 상성 배율을 ×1.5/×0.55로 올려도 그대로였다. 대안: 비행 누출 피해 1 → 2(예상: 지상 전용 단일 판 −2~3웨이브) / B3 하늘유랑단(비행 40%)에 맡기고 지금은 둔다. 서리·바람은 유틸이라 단일 판·강점 줄의 대상이 아니다(관문이 유틸을 공격 타워로 센다 — 관문 정의 확인 필요).
4. **강점·약점 위반 3종**: 서리·바람(유틸, 위와 같음), 덫(상성표는 한 번 지나가는 줄이라 미리 깔린 덫을 못 본다. 덫 피해를 28로 올리면 표는 통과하지만 단일 덫 판이 25.5로 균형형을 넘어 되돌렸다).
5. **최적화형 선택률**: 징집 4번(16종 중 3장씩)이라 징집 타워는 구조적으로 4%를 넘기 어렵다(관문 분모 정의 문제, B0 보고 §2). 궁수 29%만 실제 쏠림이다.
6. **유틸 시너지 0/6**: 핵심 4종 봇이 유틸 타워를 거의 짓지 않는다(키우기가 더 나음). 유틸을 세게 해도 수치가 안 움직여(조정 기록) 측정 장비 한계로 본다.

## 5. 알려 둘 것

- **키우기 쏠림**: 강화 효율이 새 설치와 비슷해지자 균형형이 6~7기만 짓고 Lv8~9까지 키운다(B1: 15기·최고 Lv5). 진화 그림은 잘 보이지만 "넓게 vs 키우기"가 봇에게는 키우기 쪽이다. 목표 하단(0.81·0.63)으로 둔 까닭이다. 학생 실측으로 다시 볼 것.
- **화면(U2)**: "잘 잡는 적·약한 적" 아이콘은 `matchupOf(b, type, form)`과 위 표지→아이콘 표로 만든다. 피해 숫자는 이미 상성이 들어간 값이다.
- **B3**: 종족 특성을 적에게 붙일 때 `foeTags`에 `clay`·`burrow`를 더하면 화차(흙 보호막) 같은 strongVs가 바로 작동한다. 덫·약병·박격포의 땅굴 대응은 그때 strongVs에 더한다.
- **카탈로그**: `docs/renewal/catalog/towers.md`의 기본형 수치는 이번 값과 다르다(쓰기 범위 밖이라 두었다). validate:plan은 PRD v0.5 §7.1 표와 대조한다.

## 5.5 B2.5 총괄 결정 반영(`0.9.1-renewal-candidate`)

총괄 결정: 기준 HP 44k·완충 W1~13 승인, 정답률 효과 대안 A(불꽃 중 처치 골드 ×2), 비행 누출 피해 2, 관문 측정 정의 보정, 카탈로그 수치 맞춤. 빠른 관문 전체 **PASS 23 · FAIL 9 · N/A 3**(75초).

- **불꽃 중 처치 골드 ×2**(`burning.killGoldBP` 20000, 일반·정예·대장, 파생체는 여전히 0). 정답률 효과는 3.4로 **움직이지 않았다**(×1로 재면 3.4). 불꽃 가동률이 정답률 95%에서도 약 12%라 처치 골드 증가가 수입의 2~3%에 그친다. B2 보고의 예상(+0.7~1웨이브)은 가동률을 너무 높게 잡은 것이었다.
- **비행 누출 피해 2**(`enemies.flyer.leakDamage`, 정예 비행은 정예 규칙 2, 분열 조각은 1 그대로, `leakDamageOf`). 초보형 60%가 −0.8웨이브(10.6 → 9.8) 떨어져 초반 완충 7~12웨이브를 조금 낮춰 10.3으로 되돌렸다. 초보형 50% W1~5 패배는 0%. 대공 타워가 꼭 필요해져 매의 징집 선택률이 66%(기준 60%)다.
- **보스 HP 2.5 → 2.1배**: 보스 W15 처치율 경계(0.69)를 0.75로.
- **측정 정의 보정**(r4-baseline §2, PRD R4 §7.1 아래): 유틸 6종은 단일 판·강점·약점 줄에서 빼고, 덫은 상성표 줄에서 뺀다. 징집 선택률은 후보로 나왔을 때 고른 비율 10~60%. 최적화형 롤아웃은 3웨이브(빠른 관문 77초 < 5분이라 목표는 그대로).
- 보정 뒤 새로 통과: 강점·약점 위반 0(12종), 단일 타워 판 ≥W6(최저 박격 10.5), 징집 선택률 16종 중 15종(매 66%만 밖).
- **남은 미달 9줄**: 최적화형 95% 16.4(롤아웃 3웨이브로도 균형형 95% 16.4와 같음), 초보60→최적95 6.1, 전략 효과 1.4, 정답률 효과 3.4, 사망 폭 3, 가장 좋은 단일 판(통나무 14.1, 균형형 −1.6), 형태 갈래 4개(표본 12~43), 징집 선택률(매 66%), 유틸 시너지 0/6.
- 카탈로그(`docs/renewal/catalog/towers.md`)는 B2·B2.5에서 바꾼 수치와 타워별 상성 줄을 맞췄다. 그 밖의 형태 수치가 계약과 다른 곳은 "수치는 계약을 따른다"로 적었다.
