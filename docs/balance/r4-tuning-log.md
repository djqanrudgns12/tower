# R4 밸런스 조정 기록 (B1~B3)

PRD [R4 §7.3](../renewal/prd-r4-ui-learning.md): 한 번 조정할 때 수치 3개 이하(구조 도입은 한 단계로 센다)를 바꾸고 한 줄씩 남긴다.
측정은 `npm run simulate:gate`(빠른 모드 seed 8, 4개 맵)이고 가상 플레이어 값이다(학생 실측 아님). "부분"은 `--bots` 일부만 돌린 값이다.
