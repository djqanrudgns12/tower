# 긴 경로·정확한 배치·새 에셋 · 21–30안

2026-10-27. 첨부 6개 이미지는 맵 형태만 참고하고, 기존 시안의 짧은 길·모호한 격자 배치·낮은 미술 완성도를 수정한다. 에셋은 전부 자체 제작한다. 이전 시안은 승인되지 않은 이력이며 최신 비교 화면은 `design-v0.5/index.html`이다.

## 참고에서 추출한 구조

1. 가로 전장에서 길이 위아래로 굽고 굴곡 사이의 땅이 배치 구역을 이룬다.
2. 세로 전장에서도 길이 돌아 나오며 긴 중앙 지형과 양옆 공간이 역할을 나눈다. 참고 화면의 대전 규칙은 도입하지 않는다.
3. 큰 우회와 작은 굴곡을 결합하면 같은 위치에서 경로의 여러 구간을 공격할 수 있다.
4. 되짚는 경로 사이의 길쭉한 배치 섬은 안쪽/바깥쪽 위치의 효율이 다르다.
5. 길과 배치 공간을 같은 격자 좌표에 맞춘다. 연못 등 비활성 영역도 가능하나 이번 기본 비교에서는 제외했다.
6. 넓은 U자 굴곡을 여러 번 이어 굴곡 안쪽에 복수의 기물을 둔다.

참고 게임의 아트·캐릭터·UI·고유 맵 좌표는 복사하지 않았다. 첨부를 생성 모델의 화풍 참조로 전달하지 않았으며, 형태를 글로 분석한 뒤 다른 좌표를 설계했다.

## 정확한 배치와 렌더링

이번 화면은 전체 스크린샷 생성을 대신해, 새 투명 에셋과 직접 작성한 좌표를 Canvas에서 합성한다. 모든 맵은 16×12칸이다. 타워 중심은 `(col+0.5, row+0.5)`이며 원화 표시의 긴 변은 칸 크기의 84% 이하이다. 경로·배치·렌더가 동일 좌표를 사용하므로 발판이 두 칸에 애매하게 걸치는 배치를 피한다.

`maps.json`에 경로와 배치 후보, 표본 타워를 저장했다. 맵당 타워 8개는 시안용이며 기본 지급량이나 최대 배치 수가 아니다. 적은 경로 중심선을 연속 이동한다. 타워의 칸 스냅을 적의 턴제 이동 규칙으로 확대하지 않는다. ‘격자 확인’은 타워 칸과 경로 번호, ‘동선 재생’은 경로를 따라 움직이는 적을 확인하는 기능이다. 실제 전투/경제/문항 시스템은 구현하지 않았다.

## 자체 에셋 제작

각 후보에 타워 4개와 적 2개, 총 60개 신규 도안을 생성하여 10개 투명 PNG에 저장했다. 원본 출처와 파일은 `manifest.json`, 공통/개별 지시는 `prompts.json`에 있다. Codex 내장 이미지 생성으로 만든 표본이며 Gemini가 실행·검수했다고 표시하지 않는다. 최종 생산은 기존 계획대로 Codex와 Gemini Argon이 분담하며 외부 구매 에셋을 전제로 하지 않는다.

원본을 수정하지 않고 알파 영역을 측정해 `atlas-metrics.json`에 표시용 사각형을 저장했다. 개별 파일·피벗·공격/이동 프레임을 검수한 최종 게임 자산은 아니다. 애니메이션에서는 프레임마다 알파 경계를 재정렬하면 기물이 흔들리므로, 납품 피벗과 발판을 고정해야 한다. 이번 바운딩 박스 맞춤은 정지 시안 합성용이다.

전장 바닥은 낮은 대비로 읽히게 하고, 개성은 궁수 자세·포신·의상·적 실루엣에 둔다. 단순 도형으로 미술을 축소하거나 전장을 정교한 배경 삽화로 채우지 않는다. 선택 후 작은 셀에서 사라지는 미세 장식과 과한 광원을 덜고, 1종씩 실화면 검수한 뒤 전체 타워/적과 애니메이션을 생산한다. 원문의 전체 범위를 표본 4종으로 줄이는 결정이 아니다.

## 구현에 반영할 보완

- **체류 시간 재검증:** 대략 `경로 이동 거리 / 초당 이동 칸 수`다. 기존 적 속도를 그대로 쓰면 공격 횟수·웨이브 시간·동시 적 수가 늘어난다. 선택 맵에 대해 이동 단위·사거리·스폰 간격·체력/보상·문항 노출 시간을 함께 검증한다. 81칸 안은 길이 상한 비교 후보다.
- **유효 배치 구분:** 길 외 111–146칸은 후보이지 모두 유효한 자리는 아니다. 타워별 공격 가능한 경로 길이·재접촉·출구 집중도를 계측하고 필요하면 비활성/장식 영역으로 정리한다. 기존 고정 20슬롯과 이 후보 전체 배치 중 어느 규칙도 이번 그림만으로 자동 확정하지 않는다.
- **모바일 정밀 입력:** 390px 화면의 실제 보드 폭은 약 346px, 한 칸 약 21.6px다. 화면에 들어온다고 터치 가능성이 검증된 것은 아니다. 전체 전장 보기를 유지하면서 배치 시 주변 칸 확대 패널/확인 버튼을 제공하는 안과 가로 모드를 실기기에서 비교한다. 기기별로 경로 토폴로지를 바꾸지 않는다.
- **읽기 순서:** 입구·목표·선택 칸을 먼저 보여준다. 강한 격자와 번호는 확인 모드에 둔다. IN/GOAL은 설계 확인용 표기이며 최종 성문 아트·한국어 UI로 교체한다. 상시 사거리·피해 숫자를 남발하지 않는다.
- **선택 분리:** 25번 에셋을 23번 맵에 적용하는 식으로 조합 가능하다. 선택 전 대량 애니메이션·배경 장식 생산을 시작하지 않는다. 원래 4개 학년·10종 타워 목표는 유지한다.

## 확인 범위

10개 경로와 타워 80개에 대해 직교 연결, 경로 중복 없음, 경계 이탈 없음, 타워의 경로 침범/중복 없음, 렌더 중심과 크기를 검사했다. 1520/1024/768/390/320px 가로 넘침과 격자·동선 토글을 확인했다. 화면 PNG 10장과 `inspection.json`을 저장했다. 게임 밸런스·모바일 터치·실기기 성능 승인과는 별개다.
