# 과거 탐색·검증 이력 — 실행하지 않음

2026-10-27 사용자가 41번 왕국 원정대 화풍을 선택했고 다른 프로젝트 이미지의 삭제를 요청했다. 이미지 파일은 이 폴더에 보관하지 않았다. 이곳에는 과거 비교 페이지, 생성 지시문, 맵 후보, 동작 표본 소스와 당시 검사 결과만 남아 있다.

이 자료는 최종 게임 소스나 현재 실행 가능한 데모가 아니다. 삭제한 이미지 및 이전 PC의 절대경로를 참조할 수 있다. archive/tools의 과거 스크립트는 새 디렉터리 구조에 맞춰 이식하지 않았으며 실행하지 않는다. 과거 검증 결과를 현재 제품/실기기 통과로 간주하지 않는다.
