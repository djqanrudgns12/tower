# 공간·기물 크기·하단 문제·다른 화풍 · 추가 31–40안

2026-10-27. 사용자는 v0.5의 긴 경로와 전반적 방향을 긍정적으로 평가했다. 이번 요구는 그 방향을 유지하며 반복적인 길/바둑판 느낌을 줄이고, 한글 관련 영구 장식물을 추가하고, 기물을 키우며, 하단 문제와 우측 관리 패널로 재구성하는 것이다. 최종 스타일 선택은 아직 아니다.

## 변경한 공통 구조

- 기본 좌표를 16×12에서 **14×10 후보**로 조정하고 타워의 최대 표시 크기를 칸의 84%에서 **96%**로 늘렸다. 1520px 브라우저 폭에서 이전 표시 한계 약 60.8px, 이번 약 81.7px로 약 34% 커졌다. 실제 원화의 폭/높이는 비율에 따라 다르다. 그림을 옆 칸까지 늘리지 않고 중심과 한 칸 점유를 유지한다.
- 길은 38–62칸으로, 굴곡과 반복 공격 공간을 유지했다. 칸 수를 줄인 것이 웨이브 체류 시간을 확정한 것은 아니다. 기존 맵 선택/슬롯 수/속도는 여전히 밸런스 검증 대상이다.
- 모든 맵에 **영구 장식 14개**를 넣었다. 세종대왕상, 한글 비석, 훈민정음을 모티브로 한 책, 목판 인쇄대, 나무다. 경로/장식/배치 후보를 서로 겹치지 않는 좌표 집합으로 분리했다. 장식은 실제 배치 불가이며 클릭하면 사유가 표시된다. 전투 기물처럼 구매/강화/판매하지 않는다.
- 장식 바닥도 역할을 구분한다. 나무는 녹지, 비석/동상은 석재 기념 공간, 책/목판은 공방 받침으로 표현한다. 장식의 실루엣이 경로와 타워를 가리지 않도록 한 칸 안에 넣는다. 주변 색 면은 조경 표현이며 실제 점유 칸을 확대하지 않는다.
- 전체 격자는 기본적으로 숨긴다. 배치 확인 시 칸과 장식 점유 경계를 보여준다. 화면에 드문드문 표시하는 빈자리 표시는 배치 후보의 일부이며, 그것만 배치 가능한 고정 슬롯이라는 뜻은 아니다.
- 어휘 문제는 **하단 전체 폭**을 쓰고, 우측은 기물 종류·선택 기물·역할·관리 동작의 시안을 배치한다. 데스크톱 선택지는 가로 4개, 작은 화면은 2×2다. 실제 글자를 DOM으로 렌더링한다.
- 760px 이하에서 우측 관리 패널은 접을 수 있는 관리 영역으로 전환된다. 문제 패널은 전장 아래에 남는다. 선택지를 가리는 관리 오버레이를 사용하지 않았다.

## 신규 에셋과 문화적 표현

내장 `image_gen`으로 10세트 × 9개, 총 **90개 도안**을 새로 생성했다. 3개 전투 기물, 적 1개, 영구 장식 5개를 같은 화풍으로 제작했다. 3종은 비교 표본이며 원래 10종 타워 목표를 축소한 것이 아니다. 생성 원본/출처는 `design-v0.6/manifest.json`, 실제 생성 지시는 `prompts.json`에 있다.

이전의 과도한 금속 장식·벽돌·명암·후광을 줄이고, 큰 형태와 주요 색 면을 남겼다. 도자기/점토 후보는 재질감이 더 남아 있고 만화/도트/평면 후보는 선과 색의 구분을 우선한다. 선택 후 실제 크기에서 가장 작은 장식을 추가로 정리한다.

세종대왕상과 훈민정음 관련 책/목판은 **현대 게임용 창작 조형물**이다. 특정 실물 동상, 유물의 정확한 복원, 역사적으로 검증된 복식·왕관·책 형태라고 주장하지 않는다. 최종 역사적 표현이 필요한 경우 별도 근거 검수를 한다. 사용자 요청의 한글 정체성을 표현하기 위한 것이며 모든 기물을 전통 건축에 묶는 필수 설정은 아니다.

비석의 ‘한글’과 책의 ‘훈민정음’은 그림 생성에 맡기지 않고 렌더에서 정확한 문자열로 넣었다. 임의의 고문헌 구절을 만들어 넣지 않았다. 최종 아틀라스에서는 이 위치를 명시적인 텍스트 앵커로 납품한다.

알파 경계 측정 중 인접 슬롯에서 넘어온 작은 파편을 발견해, 표시용 사각형은 가장 큰 연결 영역을 기준으로 다시 측정했다. **원본 PNG는 수정하지 않았다.** 이 처리는 정지 시안의 합성용이다. 최종 자산은 개별 투명 파일·고정 피벗·전체 프레임 가독성 검수를 받아야 하고, 애니메이션 프레임마다 바운딩 박스로 재중심 정렬하면 안 된다. Gemini Argon의 실제 실행/공동검수가 완료되었다고 표시하지 않는다.

## 다음 구현 계약에 반영할 사항

1. `cellType`은 최소 `path`, `buildable`, `decorationBlocked`로 분리한다. 장식물 ID·자산 ID·좌표·점유 크기·텍스트 앵커는 별도 데이터다. 장식물을 이동하거나 판매해서 공간을 확보하는 기능은 이번 요청에 포함되지 않는다.
2. 장식이 늘면서 사거리 효율이 바뀐다. 최종 선택 맵에서 초반/중앙/출구의 유효 슬롯과 최소 3개 배치 전략을 비교한다. 장식을 심미적으로 놓았다는 것만으로 밸런스가 확보된 것은 아니다.
3. 전체 격자는 조작 모드의 보조 정보다. 기본 화면은 자연스러운 면과 길, 고정 지형으로 읽힌다. 실제 판정은 시각 텍스처가 아닌 칸 좌표가 담당한다. 장식/타워 선택 시 해당 한 칸 경계를 명확히 표시한다.
4. UI 역할을 고정한다. 하단은 문제/오답 피드백/다음 문항, 우측은 기물 선택/설명/강화/판매다. 작은 화면에서는 관리 접기 상태를 유지하고 문제 영역의 높이를 안정적으로 확보한다. 가로·분할 화면과 안전 영역은 별도 실기기 검증한다.
5. 기물을 키워도 작은 휴대폰에서 칸은 여전히 작다. 390px 폭의 시안에서 타워 최대 표시 약 23.9px다. 배치 시 확대 영역과 확인 단계를 추가 검증해야 한다. 선택지 버튼은 이번 브라우저 확인에서 높이 72px 이상이지만, 이것이 게임 전체 접근성 승인은 아니다.
6. 일반 적·중장갑·보스의 크기 계층은 최종 세트에서 따로 정한다. 고정 장식은 적으로 보이지 않도록 공격 반응/체력바/깜박임을 주지 않는다. 역사 인물 조형물은 피격·파괴 대상이 아니다.
7. 최종 생산은 자체 제작을 전제로 Codex와 Gemini Argon이 분담한다. 먼저 선택한 화풍의 전투 기물/적/한글 비석/나무 각 1개를 실제 화면에서 확정하고, 같은 기준으로 전체 에셋을 확장한다.

## 확인한 것과 한계

10맵 모두 경로 연결·중복·범위, 경로/장식/배치 후보의 140칸 분할, 타워 60개의 칸 중심과 한 칸 이내 크기를 검사했다. 각 맵에서 장식 클릭을 배치 불가로, 빈 칸을 배치 가능으로 확인했다. 화면 1520/1024/768/390/320px 가로 넘침, 문제 패널이 전장 아래에 있는지, 선택지 높이, 모바일 관리 접기, 기물 선택과 답안 선택 표시를 확인했다. `inspection.json`에 기록했다.

전투·채점·저장·경제·강화·판매는 구현하지 않았다. 경로 재생과 배치 가능 여부는 디자인 검토용이다. 실제 휴대폰 성능·터치 정확도·학생 흥미도는 아직 검증하지 않았다. 선택한 스타일을 기준으로 다음 단계에서 확인한다.
