현재 설계 최종 수합을 막는 필수 입력은 **사용자의 디자인 선택**이다. 이름/번호 하나 또는 주방향1개와 차용할 보조 요소를 받으면 된다. 실제 시험 기기 모델과 외부 검수 도구 연결은 해당 구현/콘텐츠 단계에서 확인할 정보이며, 지금 디자인 선택을 추가로 지연시키는 필수 질문으로 만들지 않는다.
