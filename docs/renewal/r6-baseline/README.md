# R6 디자인 개편 전 기준선

기준 커밋은 `b8530172ba2d1739dd336a36e65049d687ab7748`이다. 정적 계측은 해당 커밋의 Git 트리와 파일을 기준으로 했다. 자산 그림의 픽셀 규격은 실제 WebP 헤더와 대조했다. 수치 재계산에 필요한 파일별 데이터는 [재고 원자료](inventory.json)에 있다.

## 화면 캡처와 DOM 계측

**미실행.** `resource-guard`의 `test` 프로필 공용 대기열에서 600초 동안 입장하지 못했다(종료 코드 75). 대기 중 측정에서 압축 메모리는 12.56 GiB로, 32 GiB 장비의 35% 기준(11.20 GiB)을 초과했다. 개발 서버와 Chromium이 시작되지 않아 캡처는 0장이다. 화면 글자·버튼·입력칸 개수도 미계측이다.

계획한 뷰포트는 데스크톱 1366×768, 기존 크롬북 1366×650, 폰 390×844다. [캡처 도구](../../../tools/qa/scenes.mjs)는 `--all-sizes --sizes desk,cb,phone --port 5180`을 지원한다. 기본 `desk`는 1440×900이므로 재실행 시 데스크톱 너비와 높이를 캡처 실행 설정에서 조정한다.

## CSS 디자인 토큰

[전역 토큰](../../../src/ui/styles/global.css)을 포함한 CSS 22개에서 PostCSS로 선언을 읽었다. 색은 선언에 직접 적힌 값과 사용자 정의 속성 정의를 세고, 변수 호출·주석·URL·문자열을 제외했다. 3자리 HEX는 6자리로 펼쳤다. 동일한 실제 CSS 값으로 평가될 수 있는 서로 다른 표현은 선언식 표에서 각각 셌다.

- 수치 색상 **43종, 47회**. 전역 CSS가 30종, [홈 전용 CSS](../../../src/ui/screens/home/home.module.css)가 13종을 선언한다.
- 키워드는 transparent (23), highlight (2), buttontext (1), canvastext (1), currentcolor (1). 강제 색상 모드용 값과 투명·상속 값을 수치 색상 순위에서 뺐다.
- 글자 토큰 `--fs-1`~`--fs-6`은 13·16·20·24·32·44px. `font-size`에는 13~21px의 고정 표현 9종이 59회 나온다. `font: inherit`은 1회다.
- `box-shadow`의 39종에는 `none` 1종이 포함된다. `filter`는 밝기 1.04·1.06 및 `none`이고, `drop-shadow` 선언은 0회다.
- 선언식별 전체 빈도와 위치는 원자료의 `styleTotals`, `fontLocations`, `colorLocations`에 있다.

| 속성 | 선언식 종류 | 선언 수 | 자주 쓰인 값 |

| 글자 크기 | 23 | 202 | `var(--fs-1)` 63회, `var(--fs-2)` 40회, `13px` 28회, `var(--fs-3)` 14회 |

## 디자인 부채 상위 10개

빈도와 공용화 범위, 개편 시 다시 확인해야 하는 대상 수를 기준으로 정렬했다.

1. 홈 색이 공용 팔레트와 갈라져 있다. CSS 수치 색 43종 중 13종은 홈 전용 파일에만 있다(17회).
2. 글자 크기 선언이 분산돼 있다. 공용 단계는 6개이고, `font-size` 표현은 23종이다. 13~21px의 고정 표현 9종이 59회 나온다.
3. 상자 깊이 표현이 다양하다. `box-shadow` 78개 선언에서 39종이 나오고, `none`을 뺀 38종이 토큰·인셋·직접 값에 걸쳐 있다.
4. 모서리 표현이 늘어났다. 공용 4·8px 토큰이 87회 쓰이고 전체 선언식은 13종이다. 999px 캡슐 반경은 6회 나온다.
5. 틀 개편이 공용 부품 수정으로 끝나기 어렵다. 이미지 틀 선언 15건 중 9건이 홈·전투 전용이며 `frame.lg` 소비는 0건이다.
6. 그림 집계가 두 경로에 걸친다. 배포 그림 458장 중 80장(17.5%)의 UI·설명서·지도 그림은 매니페스트에서 조회할 수 없다.
7. 종족별 보행 원화가 단일 자세에 의존한다. 전장 종족 본체 95장 모두 단일 프레임이며 정원 보병의 전용 보행 프레임은 4장이다.
8. 타워 본체 동작을 만들려면 별도 프레임 제작이 필요하다. 20종 7형태의 본체 140장 모두 단일 프레임이며 현재 동작은 변형·무기 층·트윈을 쓴다.
9. 맵 소품 배치의 변경 비용이 크다. 4개 맵에 고정 배치 458개가 있고, 263개가 길 가장자리 소품이다.
10. 전투 효과 원화 범위가 좁다. 투사체·피격 공유 텍스처 5종을 코드가 그리며 매니페스트의 효과 그림 7장은 모두 분위기용이다.
