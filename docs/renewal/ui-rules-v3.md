# UI 규정 v3 · 「그림책 원정대」 (R4 기준)

[UI 규정 v2](ui-rules-v2.md)를 대체한다(2026-11-04, [R4 PRD](prd-r4-ui-learning.md) §2). v2의 편의성 규격(§4)과 연출 규격(§5)은 아래와 어긋나지 않는 한 그대로 쓴다.

## 1. 방향

- **원화의 세계가 주인공이다.** 맵·타워·몬스터 위에 **밝은 종이 카드**와 **눌리는 키캡 버튼**을 올린다.
- 호두나무·양피지·놋쇠 재질을 CSS로 흉내 내지 않는다. 그 흉내가 "갈색 웹 폼" 느낌의 원인이었다.
- 게임다운 개성은 **원화 아이콘 16종**(상태 8 + 적 특성 8), 실제 맵 썸네일, 큰 숫자가 맡는다.

## 2. 규정

| 항목 | 규정 |
|---|---|
| 색 | 토큰 한 벌만 쓴다: `--bg` `--paper` `--paper-2` `--line` `--ink` `--ink-2` `--on-dark` `--green(-base)` `--amber(-base)` `--red(-base)` `--blue`, 막 `--scrim`. 밖의 색은 0이다(캔버스 원화 제외) |
| 글꼴 | Pretendard 하나, 굵기 400/700/800(계약 `layout.fontWeights`). 로고와 큰 숫자는 800. PRD의 표시용 글꼴(Jua)은 외부 파일을 들이지 않으려고 쓰지 않는다(총괄 결정 2026-11-04) |
| 크기 | `--fs-1`~`--fs-6` = 13 / 16 / 20 / 24 / 32 / 44px만 쓴다. 글자 크기 단계(보통·크게·아주 크게)는 문제 글자에만 적용한다 |
| 반경 | `--r-sm` 8px(버튼·입력·답안 키·고르기 칸), `--r-md` 14px(카드·창). 999px은 개수 배지만 |
| 테두리 | 카드·창 테두리는 0이다. 면 색 차이(`--paper` ↔ `--paper-2`)와 여백으로 나눈다. 입력칸만 2px `--line`. 선택·포커스는 3px `--blue` 링 |
| 그림자 | 키캡 바닥(`0 4px 0 <바닥색>`, 고르기 칸·스위치는 2~3px)과 `--float` 두 가지만 |
| 금지 | 그라데이션·블러·`text-shadow`·유리·네온·광택·반짝이·이모지, 기능 없는 리본·배너·왕관, 브라우저 기본 라디오·체크박스·select·밑줄 링크의 노출 |
| 겹 | 화면 > 카드 > 내용, 최대 2겹. 카드 안을 나눌 때는 테두리 상자 대신 `Card sunk`(한 단 낮은 면)를 쓴다 |
| 문장 | 전투 화면 상시 문장은 문제 본문을 빼고 1개 이하, 다른 화면은 3개 이하, 한 문장 30자 이하 목표 |
| 움직임 | UI 전환 120~240ms, 피드백 600ms 이하, 무한 반복 화면당 1개, `prefers-reduced-motion`이면 위치 이동 없이 투명도만 |
| 접근성 | 44px 터치, 13px 하한, 포커스가 보일 것, 6상태(기본·호버·누름·포커스·비활성·선택) |

## 3. 부품(`src/ui/kit`)

| 부품 | 쓰임 |
|---|---|
| `Button` | 변형 `primary`(시작·정답 진행), `accent`(진화·구매), `danger`(판매·끝내기), `secondary`(보조), `ghost`(글자만). 크기 `md` 44px / `lg` 56px. 한 화면에서 `primary lg`는 하나만 |
| `IconButton` | 아이콘만 있는 버튼. `label`이 화면 읽기 이름이자 호버 안내. `count`를 주면 배지가 붙는다 |
| `Card` | `float`는 바탕 위에 뜬 카드, `sunk`는 카드 안의 낮은 면 |
| `Segmented` | 2~4개 중 하나 고르기(라디오 묶음, 화살표·Home·End). 고를 수 없는 칸은 `disabled` + `onBlocked`로 이유를 한 줄 보인다 |
| `Toggle` | 켜기·끄기(role=switch) |
| `Stat` | 아이콘 + 숫자(+ 작은 이름) |
| `Modal` | 막 위의 카드 창. 포커스 가둠·Esc·연 버튼으로 포커스 복귀. 꼭 골라야 하는 창은 `dismissable={false}` |
| `ArtIcon` | 원화 아이콘(`public/assets/ui/icon.*`, `trait.*`) |

조작 아이콘은 `src/ui/icons/ControlIcons.tsx` 한 세트(24 viewBox, 선 2px, currentColor)만 쓴다.

## 4. 용어

| 쓰지 않음 | 씀 |
|---|---|
| 출정, 출정 설정, 출정 대원 별명 | 시작, 새 게임, 닉네임 |
| 징집 | 새 타워 |
| 고비 | 대장, 대장 웨이브 |
| 버닝, `○○○` | 불꽃(연속 정답 3번), 불꽃 아이콘 3칸 |
| 명예점 | 게임 중에는 숨김. 랭킹·결과에서 "랭킹 점수" |
| 장착 홈 | 화면에 쓰지 않음 |

## 5. 화면 관문(장비가 센다: `node tools/qa/scenes.mjs` → `report.json`의 `audit.slop`)

| 화면 | 버튼 | 상시 문장 | 글자 크기 종류 | 알약 | 겹 |
|---|---|---|---|---|---|
| 홈 | ≤ 8 | ≤ 3 | ≤ 5 | ≤ 1 | ≤ 2 |
| 새 게임 | ≤ 12 | ≤ 2 | ≤ 4 | 0 | ≤ 2 |
| 전투(준비·전투) | 문제 4 + 모르겠어요 + 일시정지 + 장착 타워 수 | ≤ 1(문제 제외) | ≤ 5 | ≤ 1 | ≤ 2 |
| 새 타워·진화·보물 | 카드 수 + 닫기 | ≤ 카드 수 | ≤ 4 | 0 | ≤ 2 |
| 결과 | ≤ 4 | ≤ 2 | ≤ 5 | 0 | ≤ 2 |

- 겹 수는 배경색이나 테두리가 있는 조상 사슬의 길이다. 앱 바탕 1겹을 포함하므로 위 수치에 1을 더해 읽는다.
- 문제 본문·선택지 영역에는 `data-content`를 단다. 그러면 상시 문장에서 빠진다.
- **눈 관문:** 가장 크고 대비가 높은 요소가 "지금 할 일"이어야 한다(전후 캡처로 판정).
