# UI 규정 v2 · 전투 화면 리뉴얼 방향 (R1 기준)

> **대체됨(2026-11-04):** [UI 규정 v3](ui-rules-v3.md). 이 문서의 §4 편의성·§5 연출 규격만 v3와 어긋나지 않는 범위에서 유효하다.

PRD v0.5 §12.8을 대체한다(사용자 결정 2026-10-30: 합리적으로 일부 완화). **slop 차단 항목은 그대로 두고, 재질·움직임·위계를 막던 항목만 푼다.**

## 1. 방향: 「원정대 작업대」

지금 패널이 촌스러운 이유: 갈색 테두리 웹 카드가 겹겹이 있고(판 안에 우물 안에 행), 글자 굵기·크기가 비슷하고, 설명 문장이 많고, 움직임이 없다.

- **전장이 주인공이다.** UI는 전장을 감싸는 액자이고, 전장보다 눈에 띄면 실패다.
- 재질 세 가지만 쓴다. **짙은 호두나무 틀**(바깥 프레임), **양피지 면**(읽는 곳), **놋쇠 포인트**(지금 누를 수 있는 가장 중요한 것 하나). 재질은 9-slice 이미지나 절제된 CSS(아래 §2)로 만든다.
- 정보는 **아이콘+숫자**가 기본이다. 문장은 처음 한 번 안내(코치 마크)나 길게 누르기·호버 상세에만 쓴다.
- 41번 원화의 구성을 따른다. 상단 상태 바(성문·골드·웨이브), 우측 타워 장착 홈(초상화+가격), 선택한 타워의 능력치 막대, 하단 양피지 문제판과 나무 답안 키.

## 3. 화면 관문 체크리스트(캡처로 센다)

1. 전장 면적이 1440×900에서 지금보다 줄지 않았나
2. 한 화면에 상시 문장 3개 이하, 버튼 수는 이전보다 늘지 않았나
3. 눈이 가장 먼저 가는 것이 "지금 해야 할 일"(문제 또는 설치)인가
4. 유리·네온·광택·과한 그라데이션·의미 없는 반짝이·이모지·영어 단독 라벨이 0인가
5. 재질 3종 밖의 새 재질이 생기지 않았나
6. 390×844 폰에서 겹침·가로 스크롤이 없나
7. 모션을 끈 상태에서도 모든 정보가 전달되나

## 4. 편의성 규격

| 기능 | 규격 |
|---|---|
| **끌어 놓아 설치** | 장착 홈의 타워를 전장으로 끌면 사거리 원과 놓을 수 있는 빈 자리를 강조하고, 반 칸 안의 가장 가까운 빈 자리로 붙는다. 놓으면 **확인 없이 바로 설치**한다. 골드가 모자라면 끌기 시작 때 막고 이유를 짧게 보인다 |
| **누르면 바로 설치** | 타워를 먼저 고른 상태에서 빈 자리를 누르면 바로 설치한다(설치 버튼 단계 없음). 골드가 남으면 같은 타워가 계속 선택돼 연속 설치할 수 있다. 빈 자리를 먼저 누르면 그 자리 옆에 작은 타워 고르기 메뉴가 뜨고, 고르면 바로 설치한다 |
| **실수 되돌리기** | 설치 직후 3초 동안 그 타워 위에 "되돌리기"가 뜨고 누르면 전액 환불한다(R2에 `undoBuild` 명령 필요). 끌어 놓기 오조작 대비 |
| **설치된 타워** | 누르면 타워 옆에 작은 도구 묶음(강화·가격, 판매)이 뜬다. 진화 레벨이면 강화 대신 "진화"가 뜨고 누르면 진화 카드가 열린다. 자세한 능력치는 우측 패널에 막대로 보인다 |
| **기물 크기** | 타워는 칸의 0.95~1.05배, 설치 받침은 0.8칸, 일반 적 0.6~0.75칸, 대장 1.2칸 안팎. 실제 1440×900·폰에서 캡처로 확정한다 |
| **문구 줄이기** | "빈 돌 받침을 누르거나…" 같은 상시 안내는 첫 판 코치 마크로만 보인다. 보상 안내("정답 +20골드 · +10점")는 아이콘+숫자 칩으로 바꾼다 |
| **키보드·스위치** | 기존 설치 자리 목록·키보드 선택은 유지한다(끌기를 못 하는 사용자용) |

## 5. 연출 규격 (공부가 힘이 된다)

- 정답 → 금화 2~5개가 문제판에서 골드 칸으로 날아가고, 골드 숫자가 굴러 오른다. 새로 살 수 있게 된 타워 홈 테두리가 한 번 빛난다.
- 오답 → 문제판이 짧게 좌우로 흔들리지 않는다(제출 흔들림 0 요구). 대신 고른 키가 눌린 채 붉게 바래고 정답 키가 떠오른다.
- 성문 피해 → 성문 막대가 줄어드는 전환, 막대 테두리 붉은 깜빡임 1회. 화면 전체 흔들림 금지.
- 웨이브 시작 → 전장 위 상단에 웨이브 번호 띠가 1초 내려왔다 올라간다. 대장 웨이브는 띠 색과 대장 초상화.
- 진화 → 타워에 빛기둥 0.5초, 새 형태로 바뀔 때 살짝 튀어 오름.
