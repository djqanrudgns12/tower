## 1. 2차 시안(N1~N5)이 왜 "AI Slop"으로 실패했는가

1차 시안(C1~C5)이 "어른 취향의 차분한 재질 실험"으로 반려된 뒤, 2차 시안은 반작용으로 **"초등학생 = 고채도·네온·광택·치비·병맛 밈"** 공식을 과잉 적용했다. 그 결과 이미지 생성 모델이 가장 흔히 쏟아내는 모바일 과금 광고 문법과 정면으로 겹쳤다.

1. **생성 모델의 기본 버릇(모바일 광고 Slop) 방치**: 고채도 원색, 무지개 홀로그램, 젤리/비닐 광택, 과도한 발광(bloom)과 입자 흩뿌리기가 결합해 싸구려 모바일 광고 화면처럼 보였다.
2. **타워의 정체성 붕괴 (사람·동물형 남용)**: 타워 디펜스의 핵심 매력인 "건축물·포대·방어 기계의 증축과 기능적 위용" 대신, 탑 위에 사람 사수나 동물·펫 캐릭터를 세워 유치하고 전술적 판독성이 떨어졌다.
3. **유치한 밈 적군**: 식빵·바나나·변기·개그 표정 몬스터는 잠깐 웃길 수는 있어도, 고학년(5~6학년)이 교실에서 진지하게 몰입하기엔 창피하고 가벼운 인상을 줬다.
4. **시각 위계 없는 과잉 UI**: 두꺼운 아웃라인, `-6deg` 기울기, 노랑·파랑·보라·무지개 테두리가 전장보다 크게 튀어 시선을 분산시켰다.

## 4. 3차 공통 준수 체크리스트 (AI Slop 차단)

- [x] **타워 사람·동물형 0**: 모든 타워는 건축물·포대·기계·석조 구조물. 진화는 층수·무장·기하학 구조 증축.
- [x] **화면당 주요 색 ≤6개, 무광, 단일 좌상단 광원**: 블룸·무지개·광택·랜덤 소품 0.
- [x] **한글은 HTML/CSS 웹폰트 합성만 허용**: 생성 원화 내 문자·숫자·가짜 기호 0.
- [x] **배속 단추 금지 · 평이한 용어**: `성문`, `골드`, `웨이브`, `남은 적`, `타워 설치`, `모르겠어요`, `일시정지`.
- [x] **고정 맵 `garden_u`**: `15×9` 격자, 4단 S자 구불길 41칸, 20개 설치 패드 구조 준수.
