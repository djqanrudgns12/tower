# R10 설계도 공학

남색 제도지 위에서 흰 윤곽의 포대와 황동색 기계 갑충이 움직이는 평면 전술도.

- **참고** — NASA 공학 도면에서 중심선·외형선·치수선의 위계와 평면/단면 대응을 가져왔다. 타워는 고정 기단 위에 작동부가 올라가고, 적 도판은 동일 외판을 평면과 중앙 단면으로 보여 준다. [NASA 제도 규격](https://standards.nasa.gov/node/815) · [NASA 기계 도면 작성 지침](https://s3vi.ndc.nasa.gov/ssri-kb/static/resources/NASA%20GSFC-X-673-64-1F.pdf)
- **색과 글꼴** — 배경 `#0D2236`, 제도지 `#16354F`, 격자 `#56788D`, 보조선 `#9EB9C5`, 흰 윤곽·글자 `#E9EFEB`, 적 `#D9B78D`. 글자는 HTML의 Noto Sans KR을 사용한다. [Noto Sans KR 라이선스](https://github.com/google/fonts/blob/main/ofl/notosanskr/OFL.txt)
- **조형** — 석궁 레일, 톱니 포탑, 쌍피스톤, 원형 코일은 부품의 외곽과 조립선으로 구별한다. 갑충은 등판과 궤도, 집게의 폭이 서로 다르다. 전장에는 격자 외곽 치수와 얇은 중심선만 남겨 읽을 양을 줄였다. 문제는 도면 밖의 두 열에서 읽는다.
- **양산** — 타워 20종은 기단·회전부·구동부·체결부를 공통 중심점에서 조립한다. 단계별 부품 표로 Lv2~3의 레일 보강, Lv4의 측면 지지대, Lv5~6의 넓어진 안내 레일, Lv7의 이중 작동부를 달아 140형태를 낸다. 적 8종족은 등판과 구동축 좌표를 고정하고 12개 역할을 집게 길이·궤도 폭·외판 장수로 구별한다. 4개 맵은 격자·경로·설치 좌표에서 프레임과 치수를 계산한다. 정투영 SVG 원본은 확대에 따른 해상도 손실이 없고 같은 부품으로 전장·도판·아틀라스를 재생성할 수 있다.
- **공수와 위험** — 제작 1인 기준 선 굵기·부품 규격 4~6일, 타워·적 전체 10~14일, 맵 및 축소 가독성 3~4일 추정. 장치마다 나사와 내부 선을 많이 남기면 48px에서 막혀 보이기 쉽다. 축소 출력에선 외형·작동부만 남기고 단면·치수는 도판에 배치할 수 있다.
- **크롬북** — 격자·경로는 맵 전환 때 한 번 그려 보관하고, 움직이는 적은 단계별로 내보낸 아틀라스 좌표만 갱신한다. 필터 없이 외형으로 식별한다. 실기기 프레임 시간과 저해상도 외곽선 가독성 측정은 남아 있다.
