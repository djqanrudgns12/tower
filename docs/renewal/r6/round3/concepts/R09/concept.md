# R09 기하학 미니멀

정원 길을 위에서 본 슬레이트 전술판. 청록색 고정 포대의 기단과 구리색 적의 진행 방향을 도형만으로 읽는다.

- **참고** — Infinitode 2에서 역할마다 다른 기하 윤곽을, Mini Metro에서 굽은 길을 굵은 한 줄로 이어 경로를 먼저 읽히게 하는 원리를 가져왔다. [Infinitode 2 공식 페이지](https://store.steampowered.com/app/937310/Infinitode_2__Infinite_Tower_Defense/) · [Mini Metro 제작사 자료](https://dinopoloclub.com/press/mini-metro/)
- **색과 글꼴** — 바탕 `#141D25`, 전장 `#1E2B35`, 구획 `#435360`, 글자·문제 바탕 `#E3E8E3`, 설치·포대 `#88BCB3`, 적 `#D49A78`. 한글은 HTML의 Noto Sans KR 가변 글꼴을 쓴다. 목업에 쓰인 글자 부분 집합과 라이선스를 함께 넣었다. [Noto Sans KR 라이선스](https://github.com/google/fonts/blob/main/ofl/notosanskr/OFL.txt)
- **조형** — 원형 받침에 육각 판과 V자 활대, 두 평행 포신, 삼각 공진기, 갈라진 고리를 각각 얹었다. 적은 뾰족한 선두와 겹판의 방향으로 이동 방식과 방어 성격을 드러낸다. 무광 면과 단색 선을 쓰고, 사거리와 사격 자국은 선택한 장면에 한 번만 그린다. 밝은 문제 영역에는 문항과 선택지에 필요한 요소만 놓았다.
- **양산** — 타워는 기단·몸체·작동부를 같은 축과 고정 지점에서 조립한다. 20개 역할별로 기본 실루엣을 먼저 선택하고, Lv1~7의 너비·기단 크기·부품 열 수를 표로 관리한다. Lv4에 지지대를, Lv7에 보조 작동부를 열어 140형태의 진화가 축소판에서도 이어지게 한다. 적은 8개 종족의 머리·외판·궤적 윤곽을 고정하고, 12개 역할별로 외판 수·길이·내부 틈을 바꾼다. 네 맵은 경로 셀·설치 칸으로 격자와 길을 다시 그린다. SVG 원본은 확대에도 윤곽이 매끄럽고, 배포 시 크기별 아틀라스를 일관되게 뽑을 수 있다.
- **공수와 위험** — 제작 1인 기준 부품 체계와 48px 대조 3~4일, 타워·적 전체 7~11일, 맵과 가독성 조정 2~4일 추정. 후보의 실루엣이 비슷해지면 색보다 외곽의 비율과 빈 공간을 조정한다. 추상적인 인상은 크기가 작은 적에서 특히 강해질 수 있다.
- **크롬북** — 전장·설치 칸은 맵 인입 시 한 번 그리고 타워·적은 사전 래스터화한 아틀라스에서 다시 쓴다. 필터·그림자 효과를 생략한다. 실제 크롬북에서 동시 적 최대 수와 해상도별 프레임 시간을 확인하는 단계가 남았다.

## 재현

저장소 루트에서 아래 명령을 실행하면 Playwright Chromium이 화면 3장을 차례로 캡처하고 `cwebp -q 90`으로 변환한다. 지도는 `garden_u`, 문제는 3학년 공개 문항 `g3-argon-0001`을 읽는다.

```sh
node docs/renewal/r6/round3/concepts/R09/mock/capture.mjs R09
```

같은 명령 뒤에 `--html a-battle`을 붙이면 직접 열 수 있는 HTML을 표준 출력으로 내보낸다.
