## 1. 콘셉트 요약
- **한 줄 콘셉트**: 등고선·그리드 전술 지형도 위에 1px 모따기 다크 UI와 무인 기계 포대·공성 드론을 정갈하게 올린 냉철한 전술 디펜스
- **참고 게임·작품 및 추출 원리**:
  - [Arknights (공식)](https://www.arknights.global/) — 차갑고 정돈된 무광 다크 패널, 1px 헤어라인, 모따기(chamfer), 강한 숫자 위계(`tabular-nums`)
  - [Defense Grid (Steam)](https://store.steampowered.com/app/18500/Defense_Grid_The_Awakening/) — 기계식 포대 증축과 전술 동선 위계
  - [Infinitode 2 (Steam)](https://store.steampowered.com/app/937310/Infinitode_2__Infinite_Tower_Defense/) · [Mini Metro (Steam)](https://store.steampowered.com/app/287980/Mini_Metro/) — 기하학·지형도 기반의 기능미와 색 절제
- **핵심 방향**: 1px 얇은 헤어라인, 45° 모따기(chamfer) 무광 다크 패널, 고정폭 숫자 위계(`tabular-nums`)를 갖춘 냉정하고 정돈된 전술 UI와 등고선 전술 지형도 기반의 절제된 전장 일러스트 결합.
- **대상 적합성**: 초등 3~6학년 어휘 학습 타워 디펜스에서 유치한 병맛·모바일 과금 광고 문법을 배제하고, 고학년도 몰입할 수 있는 정돈된 전략 보드·기계 포대 디자인 채택.

## 3. 후보 원화 선별 및 AI Slop 차단 기록
총 9장(`battle-v1..3`, `towers-v1..3`, `enemies-v1..3`)을 생성·검수하여 아래 기준으로 최종 1안씩 선별했다.

| 구분 | 선별안 | 선별 이유 및 탈락안 검수 결과 |
|---|---|---|
| 전장 (`a-battle`) | `battle-v3` | 등고선·십자(`+`) 그리드 지형도 표현이 가장 정교하며 좌상단 진입(`>>>` 앰버)과 우하단 성문(`>>>>` 틸) 방향 화살표가 모두 정방향. (`battle-v1`은 우하단 성문 화살표가 역방향으로 찍혀 탈락, `battle-v2`는 등고선 지형도보다 벙커 벽면 중심이라 R04 주제 적합도에서 v3 우세) |
| 타워 (`b-towers`) | `towers-v1` | 사람·동물형 완전 배제. Lv1→Lv4→Lv7의 포신·장갑·원형 레이더 증축 위계가 가장 명확하며, 면 분할이 깔끔해 `48×48px` 축소 시 뭉개짐이 없음. (`towers-v2`는 Lv7 레이더 접시 부재, `towers-v3`는 격자형 레이더와 리벳 디테일이 48px에서 다소 복잡) |
| 적군 (`c-enemies`) | `enemies-v1` | 4종 일반 기계·수정 구조체와 2배 체급 다족 공성 보스의 실루엣 분리가 가장 선명. 특히 `결정 코어 보행체`가 인간형 팔다리(`enemies-v2`) 없이 순수 3족 기계 프레임으로 구현되어 `32×32px`에서도 즉시 구별됨. |

## 4. 유닛 구성 (기계·구조체 전용)

### 타워 (총 6종)
- **궁수 계열 진화**:
  1. `Lv1 경량 자동 레일포탑` — 단일 직사 레일건, 틸 광학 조준기
  2. `Lv4 2연장 장갑 포대` — 쌍열 포신 + 모따기 장갑 기단
  3. `Lv7 4연장 레이더 감시포탑` — 4연장 포신 + 상부 탐지 레이더 접시
- **지원·특수 Lv1 3종**:
  4. `Lv1 곡사 박격포대` — 유압 지지대 + 대구경 곡사 포신
  5. `Lv1 파동 감속 중계탑` — 3중 틸 공명 링 수직 타워
  6. `Lv1 프리즘 레이저탑` — 삼각 금속 프레임 + 중앙 다면체 수정 집속 코어

### 적군 (총 5종)
1. `정찰 4족 기계체` (일반 · 고속 정찰) — 경량 4족 프레임, 틸 광학 슬릿
2. `장갑 갑충 드론` (일반 · 중장갑) — 낮은 분절 갑각, 앰버 이음매
3. `늑대형 추적기` (일반 · 추적 돌격) — 예각 스텔스 기체 실루엣
4. `결정 코어 보행체` (일반 · 에너지 결정) — 3족 지지대 내 노출형 틸 수정 코어
5. `중장갑 다족 공성 기체` (보스 · 공성 중기체) — 전면 중장갑 방패, 상단 포탑, 다족 기동부

## 5. 화면 구성 및 체크리스트 검증
- **전투 화면 (`a-battle.webp`, 1280×720)**:
  - 상단 좌측 HUD: `성문 20 / 20`, `골드 240`, `웨이브 3 / 10`, `남은 적 12`
  - 상단 우측 제어: `일시정지` 단일 단추 (**배속 단추 없음**, 세계관 말투 배제)
  - 우측 타워 설치 도크: Lv1 타워 4종 크롭 아이콘 + 명칭 + 비용
  - 하단 어휘 문항 패널: `‘짐작하다’의 뜻으로 알맞은 것은?` / 1~4 선지 / `모르겠어요`
- **타워 시트 (`b-towers.webp`, 1280×720)**: 6종 원화 + 한글 명칭 + 하단 **48×48px 축소 판독 띠**
- **적군 시트 (`c-enemies.webp`, 1280×720)**: 5종 원화·특성 + 하단 **32×32px 축소 판독 띠**
- **산출물 규격 확인**:
  - `docs/renewal/r6/round3/concepts/R04/{a-battle,b-towers,c-enemies}.webp` 생성 완료
  - 저장소 내 PNG 0개, 폴더 총 용량 3MB 이하

## 6. 왜 유치하지 않은가 / 왜 과하지 않은가

- **왜 유치하지 않은가**: 전술 지형도·기계식 포대·4족 메카 드론·`IBM Plex Sans KR` 고정폭 숫자 위계를 사용해 초등 5~6학년이 '진짜 전략 게임(e스포츠·택틱스)'을 다루는 성취감을 느끼게 만든다.
- **왜 과하지 않은가**: 6색 무광 팔레트(`#12161B`, `#1D242C`, `#4A5563`, `#B8C0C8`, `#E69F24`, `#2FB5A3`)와 1px 헤어라인만 사용해, 어두운 UI가 오히려 밝은 앰버 핵심어와 4지선다 문항을 도드라지게 만든다.

## 7. 양산 공정 · 공수 · 크롬북 성능

- **양산 규모 및 공정**: 타워 20종×7형태(140장)·적 8종족×12프레임(96장)·맵 4종을 **모듈형 Blender 3D 기계 파츠 조립 + 무광 툰/엣지 프리렌더(또는 통일 선화 리터칭) + 등고선 SVG/타일맵 합성**으로 양산한다.
- **예상 공수 및 위험 요소**: 기체/포대 모듈 킷 3일 + 타워 20종 7일 + 적 8종족 5일 + 지형도 맵 4종 2일 = **약 17인일**. 무채색 슬레이트 기체들이 전장에서 묻힐 위험은 적군·아군별 앰버/틸 포인트 시그널 면적으로 통제한다.
- **크롬북 성능**: 등고선 지형도는 경량 벡터/저용량 타일(`≤ 150KB`), 유닛 아틀라스 포함 전체 번들 `≤ 1.7MB`, 블룸·반투명 블러 0으로 학교 크롬북에서 안정적 **60fps** 달성.

## 비평가 평가


- **모바일·PC 게임 아트 디렉터**: **`7.5 / 10`** *(현대 전술 메카 대안)*
  - 장점: 100% 무인 기계 포대 진화(`1포신 → 2연장 → 4연장+레이더`)가 기능적으로 가장 논리적이며, *Arknights*·*Into the Breach* 풍의 6색 슬레이트/틸/앰버 절제와 얇은 선 UI 완성도가 매우 높음.
  - 개선 여지: 어두운 길 위 회색 적군 시인성(`32×32px` 띠 포함)과 우하단 성문 존재감을 높이고, 우측 타워 패널 하단이 4연장 포신 끝을 가리지 않게 여백을 주면 완벽.
- **초등 6학년 플레이어**: **`9.3 / 10`** *(★ 초6 원픽 1위)*
  - 평: 미래 SF 밀리터리 간지로 초6이 제일 좋아할 스타일. 레일포탑 4연장 진화와 방패·포탑 달린 다족 보스 로봇이 유치함 0%이고, 어두운 길 위 적 대비와 글자 밝기만 살짝 높이면 완벽함.
