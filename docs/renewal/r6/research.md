## 1. 현행(R5) 문제 진단 — 왜 "AI slop"처럼 보이는가

기존 캡처([02-battle-desk.webp](../qa/r5/02-battle-desk.webp), [01-home-cb.webp](../qa/r5/01-home-cb.webp), [03-cards-desk.webp](../qa/r5/03-cards-desk.webp), [landing-baseline/01-home-desk.webp](../qa/landing-baseline/01-home-desk.webp)) 분석 결과, 현행 화면은 다음 5가지 구조적 결함을 안고 있다.

1. **전장의 시각 중심·깊이 부재**: 1단 평면 초록 바탕에 덤불·돌·통나무가 난수처럼 흩뿌려져 있고, 설치 받침 20개가 가장 밝은 회색 사각형으로 떠 있어 타워보다 받침이 더 눈에 띈다. 고저차·빛 방향·접촉 그림자가 없다.
2. **색 위계 붕괴**: 화면 테두리(갈색 참나무)와 바탕(풀색)이 화면 전체의 시각 무게를 잡아먹고, 타워 원화들도 구리·나무색에 몰려 48px 크기에서 서로 구별되지 않는다.
3. **홈 화면의 감정 고리 부재**: 닉네임·학교 입력칸, 작은 탭, 베이지 상자가 빽빽해 게임 첫 화면이 아니라 '관리자 입력 서식'으로 보인다. 첫눈에 시선을 끄는 대표 캐릭터·배경이 없다.
4. **낡은 스큐어모피즘과 무미건조한 보상(Juice 부재)**: 무거운 나무 9-slice 틀과 정적인 4지선다 문제 패널 때문에, 연속 정답·타워 진화·웨이브 승리 순간의 쾌감이 전혀 터지지 않는다.
5. **AI 생성 티 잔존**: 원화 간 선 굵기·원근·명암 단계가 미세하게 어긋나고, 작은 크기로 줄였을 때 실루엣이 뭉개진다.

## 2. 2023~2026 글로벌·국내 디자인 레퍼런스 조사

Game UI Database, Interface In Game, Behance, Dribbble, Pinterest, Steam의 최신 캐주얼 전략·디펜스·교육 UI 사례를 조사해 4가지 핵심 트렌드를 도출했다.

| 트렌드 축 | 대표 레퍼런스 | R6 적용 시사점 |
|---|---|---|
| **① 무광 미니어처 디오라마** | *Thronefall*, *Tiny Glade*, *Dorfromantik*, *Hexguardian*, [Isometric House](https://www.behance.net/gallery/215961033/Isometric-House) | 과도한 텍스처 노이즈를 끄고, 단층 언덕 + 좌상단 단일 광원 + 깊은 접촉 그림자만으로 장난감 같은 고급 입체감을 만든다. |
| **② 대담한 플랫 포스터 & 촉각 UI** | *Mini Motorways*, *Monument Valley*, *Wildfrost*, *Dicey Dungeons*, *Duolingo*, [Astromatik](https://www.behance.net/gallery/253529557/Astromatik-App-Branding-UXUI) | 2단 색면 + 굵은 잉크 테두리 + 하드 오프셋 그림자(`4px 4px 0`)는 크롬북에서도 1px도 뭉개지지 않고 정보 위계가 가장 명확하다. |
| **③ 고도파민 셀 셰이딩 & VFX 루프** | *Brawl Stars*, *Cookie Run: Kingdom*, [UI FX (Karl Duche)](https://kr.pinterest.com/pin/293859944454698137/), [Void Conqueror](https://dribbble.com/shots/27278837-Casual-Game-UI-Kit-Void-Conqueror) | 젤리 입체 버튼, 캐릭터 표정 연기, 히트스톱·스쿼시-스트레치·코인 분수가 '어휘 정답 → 타워 강화' 쾌감을 폭발시킨다. |

### 조사에서 확정한 R6 공통 UX 개선 원칙
- **홈 화면**: 닉네임·학교 텍스트 입력칸 나열 제거 → 상단 프로필 칩(`하늘바람 · 서울참나무초`)으로 축약하고, 좌측 풀블리드 히어로 일러스트 + 우측 학년 선택·거대 `게임 시작` CTA·주간 랭킹 TOP 3로 재편.
- **전투 화면**: 전장 가시 영역 70% 이상 확보. 상단 얇은 알약 HUD + 우측 타워 도크 + 하단 플로팅 퀴즈 바로 재배치.
- **용어 정제**: '수호·출정·징집·작전실·명예점' 등 오글거리는 표현을 모두 걷어내고 `게임 시작`, `연습하기`, `랭킹`, `오답 노트`, `새 타워 설치`, `남은 적` 등 평이한 한국어로 통일.
- **AI slop 차단**: 생성 원화 안에 문자·숫자·가짜 한자·낙관 삽입을 전면 금지하고, 모든 한글 UI는 실제 상업 무료 웹폰트(`Pretendard`, `SUIT`, `Gmarket Sans`, `Gowun Batang`, `Jua`, `Black Han Sans`) 기반 HTML/CSS로 합성.

## 4. 총평 및 최종 추천

### 1순위 추천: **C4 · 하이퍼 팝 아케이드**
- **선정 이유**:
  1. **목표("눈길·도파민·초등 몰입")와 100% 직결**: 시안 결과물(`b-home.webp`, `a-battle.webp`, `f-dopamine.webp`)에서 확인되듯, 3~6학년 학생이 첫 화면을 보자마자 "재밌는 게임이다!"라고 느끼게 만드는 감정 고리가 5종 중 가장 강하다.
  2. **어휘 정답 → 보상 쾌감 극대화**: 젤리 버튼 눌림, 히트스톱 33ms, 골드 코인 분수, 치비 캐릭터 점프가 학습 피로도를 가장 효과적으로 상쇄한다.
  3. **전장 가독성 확보**: R5의 갈색·풀색 단조로움을 완전히 벗어났고, 바닥을 단순화하고 캐릭터·타워에 2단 셀 명암 + `#1E1B3A` 아웃라인을 적용해 48px에서도 즉시 읽힌다.
- **실행 조건(단서)**: 양산 공수(22~25일)를 줄이기 위해 타워 진화형(140장)은 **기본 수호자 캐릭터 + 건물 기단·지붕 파츠 스왑(Spine 2D)** 방식으로 모듈화하고, 과한 블룸을 금지해야 한다.

### 2순위 추천(브랜드 차별화 대안): **C3 · 단청 모던 민화**
- **선정 이유**: 한국어 어휘 학습 앱이라는 정체성과 `moon_dokkaebi`·`kiln_pottery` 등 기존 종족 설정이 놀라울 만큼 자연스럽게 맞물린다. 밝은 한지(`#F7F2E4`) 여백 덕분에 장시간 문제를 풀어도 눈 피로가 가장 적고, 시장 어떤 경쟁 앱과도 겹치지 않는 독보적 품격이 있다.
- **참고**: 기술·성능·양산 속도 최우선 시 **C2(네오 포스터, 14~16일)**, 시각적 고급감·3D 입체 보드게임 감성을 원할 시 **C1(미니어처 블록 공방, Tripo→Blender)**이 최적의 선택지다.
