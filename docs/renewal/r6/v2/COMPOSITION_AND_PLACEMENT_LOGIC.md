## §3. 완벽한 기물 배치 6대 수학적 불변식 (`Placement Invariants`)

### 불변식 ① 코너 이탈 방지 베지어 반경 상한 (`Corner Stay-Inside`)
현행 [scene.py](../../../../tools/r6/map/scene.py#L162)의 코너 라운딩 `r = 0.66칸`은 2차 베지어 중점이 꼭짓점에서 $0.33\sqrt{2} = 0.467$칸 안쪽으로 파고들어 도로 반폭 `0.29칸`보다 **`0.177칸` 연석 바깥을 밟는 결함**을 만든다([geometry.ts](../../../../src/domain/geometry.ts)의 적은 90° 직교 축으로 이동).

$$r \le \sqrt{2}\,(W_{\text{road}} - m_{\text{foot}})$$

- V2 도로 반폭 $W_{\text{road}} = 0.34$칸, 적 발 여유 $m_{\text{foot}} = 0.06$칸 적용 시 수학적 상한은 **`0.396칸`**이다.
- **V2 확정 코너 반경**: **`r = 0.38칸`** (포장 안쪽 여유 `+0.011칸` 이상 상시 확보, 적 발밑 이탈 `0px`).

### 불변식 ② 도로 연석–설치대 물리 클리어런스 (`Pad-Curb Clearance`)
- V2 연석 외곽 반폭 $W_{\text{curb}} = 0.41$칸, 설치대 외곽 반경 $R_{\text{pad}} = 0.435$칸(월드 지름 `45.2px`).
- **직교 인접 클리어런스**: $1.00 - (0.41 + 0.435) = \mathbf{0.155\text{칸}} \approx \mathbf{8.1\text{px}}$
- **코너 내측 대각선 클리어런스**: $\sqrt{2} - \frac{0.38}{\sqrt{2}} - (0.41 + 0.435) = \mathbf{0.300\text{칸}} \approx \mathbf{15.6\text{px}}$

### 불변식 ③ 사선 수직 스택 금지 & 타워 머리→뒤쪽 설치대 비가림 (`Anti-Stacking & Head-Clearance`)
사선 투영에서 `(dx, dy) = (1, 1)` 두 슬롯의 화면 중심 차이는 `(+10.68px, +37.06px)`에 불과해 앞 타워 머리가 뒤쪽 패드를 그대로 덮어 오탭을 일으킨다. 반면 `(dx, dy) = (1, -1)`은 `(+72.76px, -5.44px)`로 가로 공간이 넉넉하다.

1. **사선 수직 스택 금지**: 모든 설치대 쌍 $(s_i, s_j)$에 대해 $(\Delta x, \Delta y) \notin \{(1, 1), (-1, -1)\}$.
2. **최소 화면 이격 거리**: 모든 설치대 쌍의 월드 화면 중심 거리 **`minScreenDist ≥ 56px`** (실제 전 형태 달성 **`61.8 ~ 73.0px`**; 패드 지름 `45.2px` 대비 최소 `+16.6px` 물리 여백).
3. **근수직 열 간격 하한**: $|\Delta x_{\text{screen}}| < 26\text{px}$인 두 설치대는 **`|Δy_screen| ≥ 48px`** 준수 (실제 달성 **`58.3 ~ 74.1px`**).
4. **전경 환경 소품 차폐 금지**: 타워/경로보다 화면 앞쪽(`y_prop > y_target`)에 놓이는 소품(바위·나무·모놀리스)은 `propHeightAboveFoot < (y_prop - y_target) - 14px`를 만족해야 하며, 모든 설치대·경로 중심의 전경 알파 가림은 `≤ 15%`로 제한한다.

### 불변식 ④ 전술 화력 가치 분포 예산 (`Tactical Firing-Value Budget`)
- 대표 사거리 반경 $R = 2.8$칸 내 닿는 경로 셀 수 $V(s)$로 전술 가치를 정량화한다:
  - **S급 교차 요충지**: $V(s) \ge 9$
  - **A급 주력 방어지**: $5 \le V(s) \le 8$
  - **B급 견제·입구/출구 마감**: $3 \le V(s) \le 4$
- **배치 하한**: 죽은 설치대($V(s) < 3$) **`0개`**, 최근접 경로 거리 $d_{\min} \le 2.3$칸, 포털 기둥 반경 `1.15칸` 내 슬롯 설치 금지.
- **특수 설치대 규칙**: 화면 동시 종류 **`≤ 2종`**(`high` 언덕 설치대: 3단 기단·높이 증가 **`≤ 8px`**로 [EnemyFootprint](../../../../src/game/r6/padOutline.ts) 계약 보존 + ▲깃발, 사거리 +15% / `bright` 빛 설치대: 크림 `#F3E6C4` 0.5Hz 별무늬, 공격 +10%). 반드시 **S급 최상위 슬롯**에만 배정한다.

### 불변식 ⑤ 끊김 없는 연속 도로 UV · `gateBack/Front` Y-깊이 분할 · `0.00칸` 누수 동기화
- 단일 중심선에서 입구 원점 누적 UV(문턱에서 UV 리셋 금지)를 생성해 입구 → 다리 → 문턱(`portalThreshold = exit + 0.35u`) → **포털 내부(`portalInterior = exit + 0.90u`)**까지 단일 연결 성분으로 잇는다.
- 현행 [combat.ts](../../../../src/domain/combat.ts#L874)의 문턱 `0.43칸` 전 조기 `leak` 결함 제거: 2.1.0 신규 맵은 최종 웨이포인트 시각 종점을 `portalInterior`와 일치시키고, 문 통과 구간(`signedDist >= -0.30칸`)에서 `portalPassage(foot, progress, portal): Passage`가 아래 깊이를 강제한다:
  - `gateBack`: `DEPTH.units + gatePlaneY - 0.5`
  - `enemy` (본체 + 4방위 윤곽 + 그림자 + HP바 + 상태표시): `DEPTH.units + gatePlaneY + 4`
  - `gateFront`: `DEPTH.units + gatePlaneY + 18`
  - 포털 개구 사다리꼴/아치 클리핑으로 적이 문턱 너머 **성문 내부로 걸어 들어가며 자연스럽게 가려진 뒤 정확히 1회 `leak` 처리**된다(잔상 `0`).

### 불변식 ⑥ 자동화 기하 검증기 (`tools/r6/map/validate_layout.py`)
16전장 JSON과 Blender 분리 마스크(`terrain`, `road`, `gate-back`, `gate-front`, `pads`)를 입력받아 아래 8항목이 1건이라도 실패하면 빌드 파이프라인을 중단한다:
1. `dockHits == 0` (`x ≥ 75% ∧ y ≤ 55%` 영역 경로·슬롯 0개)
2. `gateAlphaBounds ⊆ [76..88]% × [63..78]%` (`normal` 제외), 화면 외곽 잘림 `0px`
3. `minScreenDist ≥ 56.0px` 및 `worstNearVertGap ≥ 48.0px`
4. `(dx, dy) ∈ {(1, 1), (-1, -1)}` 스택 `0건`
5. 베지어 코너 반경 `r ≤ 0.396칸`
6. 모든 슬롯 `V(s) ≥ 3`, `dmin ≤ 2.3칸`, `slots ∩ pathCells = ∅`
7. 도로 알파 마스크 단일 연결 성분(`connected_components == 1`) 및 매 픽셀 축이동선 100% 피복
8. `gateBack ∩ enemy ∩ gateFront` 통과 시 발점 부호 거리·개구 클리핑 오차 `0px`

### 5.2 Blender 5.2.3 LTS 4요소 하이브리드 툰-페인티드 셰이더 (`scene.py` V2)
1. **4단 소프트-스텝 광원 램프**: $\vec{N}\cdot\vec{L}$ 임계값 `(0.13, 0.49, 0.79)`, 명도 밴드 `(0.74, 0.88, 1.00, 1.12)`. 잔디 평면 경계만 `B_SPLINE` 5% 블렌드로 딱딱한 밴드 계단 완화.
2. **접촉 차폐(`ShaderNodeAmbientOcclusion`, `Distance = 0.45`)**: 등고선 립 아래·연석 접합부·포털 기둥 바닥의 접촉 음영을 자동 생성해 지면 부유감을 없앤다(기존 수동 그림자 중복 금지).
3. **절차 미세 결(`ShaderNodeTexNoise`)**: scale `18~42`, detail `4.0`, 명도 편차 `±4%` 범위로 석판 결·초원 결·절벽 암반 입자를 부여해 플라스틱 단색을 회화적 S++ 디오라마 질감으로 승격한다.
4. **선별 Freestyle 윤곽**: `#12161B`, 두께 `0.80 × densityScale`, `crease_angle = 52°`를 **랜드마크(`gate-back`, `gate-front`, `entrance`, `bridge`, `monolith`)·절벽 립·설치대** 컬렉션에만 적용하고, 잔디 평면은 끄기로 설정해 화면 과밀을 방지한다.
