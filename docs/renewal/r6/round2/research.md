# R6 2차 디자인 개편 · 2025~2026 초등 인기 게임 심층 조사 (`research.md`)

> **조사 기준일**: 2026-11-24  
> **목적**: 어른 취향의 차분한 재질 실험으로 전면 반려된 1차 시안(C1~C5)을 폐기하고, **"초등 5학년이 보자마자 '이거 하고 싶다'고 외치는가"**를 유일한 기준으로 삼아 인기 게임들의 매력 원리만 추출해 5개 독창적 시안(N1~N5)을 설계한다.  
> **원칙**: 특정 인기 게임의 이름·캐릭터·로고·화면 배치를 복제하지 않고, 시각·UI·캐릭터·보상 연출의 **원리만** 도출해 어휘 타워 디펜스에 재해석한다.

## 2. 2025~2026 한국 초등학생 게임 트렌드 & 유머 코드

### 2-1. 국내 초등 인기 TOP 판도 (모바일·PC·콘솔 종합)
- **양대 산맥 — 브롤스타즈(Brawl Stars) & 로블록스(Roblox)**: 한국 초등 3~6학년 MAU·체류 시간 최상위권을 양분. 브롤스타즈는 3분 내외 짧은 템포·강렬한 캐릭터·쉬운 조작과 상자/스타 드롭 보상으로, 로블록스는 *Grow a Garden*, *Steal a Brainrot*, *Pet Simulator 99*, *Adopt Me*, *RIVALS* 같은 유행 체험(Experience)을 친구들과 함께 돌며 밈과 수집 경제를 소비하는 구조로 압도적 지지를 받는다. ([뉴시스 보도](https://www.newsis.com/) · [모바일인덱스](https://www.mobileindex.com/))
- **유튜브 시청 → 즉각 플레이 선순환**: 초등학생은 직접 플레이만큼 유튜브 쇼츠·크리에이터 영상을 통해 유행을 습득한다. 로블록스의 신규 밈 게임, 브롤스타즈 신캐/하이퍼차지, 포켓몬 카드 언박싱, *스플래툰 3* / *마리오 카트 월드* / *슈퍼 마리오 원더* 플레이 영상이 곧바로 "나도 해보고 싶다"로 직결된다.
- **수집·교환 문화 (포켓몬 · 쿠키런: 킹덤 · 메이플스토리)**: *포켓몬 카드 게임 Pocket*의 팩 뜯기와 홀로그램 카드, *쿠키런: 킹덤*의 탱글한 캐릭터와 가챠 연출, *메이플스토리/메이플 키우기*의 아기자기한 2D 성장감과 귀여운 몬스터가 3~6학년 전반에 깊이 뿌리내려 있다.
- **초등 유머 코드 — 'Italian Brainrot' & 병맛 밈 (2025~2026)**: 2025년 틱톡·쇼츠에서 폭발한 *Italian Brainrot*(신발 신은 상어 *Tralalero Tralala*, 악어 폭격기 *Bombardiro Crocodilo*, 통나무 캐릭터 *Tung Tung Tung Sahur* 등)이 로블록스 *Steal a Brainrot*, *Plants vs. Brainrots*로 이어지며 초등학생 사이에서 "말도 안 되게 웃기고 엉뚱한 혼종 생물"이 대세 유머 코드가 되었다. 심각한 판타지 괴물보다 **표정이 뻔뻔하거나 허당기 넘치는 기상천외한 적**에 아이들이 훨씬 크게 반응한다.
- **학부모·교사 시선**: 과도한 현질(로벅스/가챠)과 유해 채팅은 강하게 경계하지만, *마인크래프트*나 *동물의 숲*처럼 **창의성·학습·전략성이 있고 폭력성이 순화된 게임**에는 우호적이다. 따라서 "겉모습은 브롤/로블/쿠키런급 도파민 + 본질은 건전한 초등 어휘 학습(과금/채팅 없음)" 조합이 아이와 학부모 모두를 잡는 열쇠다.

## 4. 우리 어휘력 타워 디펜스에 가져올 것 10가지

1. **타워 = 살아 숨 쉬는 캐릭터(건물 금지)**: 건물만 세우지 않고, 2~2.5등신 캐릭터 자체가 활·대포·마법·스플래시 무기를 쏘며 정답을 맞히면 함께 환호한다(*BTD6·PvZ·스쿼드 버스터즈*).
2. **Lv1 → Lv4 → Lv7 극적 실루엣 대변신**: 단순 수치 증가가 아니라 모자·망토·무기·오라·동반 펫까지 실루엣이 3단계로 확 바뀌는 포켓몬/BTD6식 진화 쾌감을 준다.
3. **웃기고 뻔뻔한 밈 적군(고블린 금지)**: 콧물 슬라임, 비명 토스트오리, 목긴 멍청닭, 오타 벌레, 소파감자 대왕처럼 아이들이 보자마자 "ㅋㅋㅋ" 웃는 표정·소품 있는 적을 배치한다(*Italian Brainrot·PvZ·스텀블 가이즈*).
4. **두꺼운 외곽선 + 3D 압출 베벨 UI 키트**: Pretendard 알약과 크림 카드 대신 `paint-order: stroke fill` 굵은 아웃라인 한글 게임 폰트(Black Han Sans, Jua, Do Hyeon, Cafe24 써라운드, 여기어때 잘난체 등)와 입체 베벨 눌림 단추를 쓴다(*브롤스타즈·로블록스*).
5. **보편적 4~5단계 희귀도 색 체계**: **일반(슬레이트/실버) → 희귀(스카이 블루) → 영웅(바이올렛/마젠타) → 전설(골드 + 무지개 홀로그램)** 로 카드·진화·보상 가치를 0.2초 만에 전달한다(*클래시 로얄·포트나이트·Pet Sim 99*).
6. **첫 화면(홈)의 '영웅 쇼케이스 + 거대 PLAY 버튼' 법칙**: 어른 웹앱 같은 설명 카드 나열을 버리고, 화면의 주인공은 캐릭터/펫/아바타/필통 성이며 거대하고 누르고 싶은 시작 버튼이 시선을 꽂는다.
7. **고정 15×9 전장 + 명확한 20개 설치 패드 + 콤팩트 퀴즈 도크**: *킹덤 러시*처럼 어디에 타워를 놓을지 한눈에 보이는 발판과 *PvZ/BTD6*처럼 맑은 길·잔디 분리 위에 하단 4지선다+`모르겠어요` 퀴즈 트레이를 배치한다(배속 UI 없음).
8. **정답 순간 도파민 폭죽 (콤보 + 히트스톱 + 코인 비행)**: 정답을 맞히면 버튼 스쿼시-바운스 + 화면 상단 콤보 폭발 + 골드가 알약으로 날아가며 전장 타워들이 일제히 크리티컬을 터뜨린다.
9. **카드 팩 개봉 / 진화 세리머니**: 새 타워 획득이나 Lv4/Lv7 진화는 별도 극적 순간(방사형 광선·카드 뒤집기·무지개 테두리 반짝임)으로 연출해 "한 판 더!" 동기를 만든다(*TCG Pocket·브롤 스타 드롭*).
10. **과금·채팅 없는 안심 설계 (아이도 부모도 OK)**: 외형과 손맛은 최신 인기 모바일 게임급이지만, 가짜 결제 팝업·현질 유도·채팅창 없이 순수 어휘 실력과 전략만으로 모든 희귀 타워와 진화를 해금한다.
