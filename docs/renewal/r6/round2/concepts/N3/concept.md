# N3 · 큐브 아바타 블록월드 (Cube Avatar Block World)

> **"햇살 반사 토이 블록 + 내가 꾸민 블록 아바타가 전장에 직접 출격해 응원·지휘하는 브레인롯 네모 밈 타워디펜스"**
> 대상: 초등학교 5학년 (1280×720 가로형 웹/크롬북 기준)

---

## 4. 손맛(마이크로 인터랙션) 타이밍 명세

| 인터랙션 | 목표 시간 (ms) | 물리/시각 피드백 |
|---|---|---|
| **스터드 블록 버튼 누름/뗌** | `60ms` 눌림 / `90ms` 복원 | `translateY(+4px)` 이동 + 하드 섀도 `6px → 2px` 압축, 가벼운 플라스틱 브릭 "딸깍" 효과음 |
| **타워 핫바(1~4) 선택** | `80ms` | 선택 슬롯 테두리 `#FACC15` 점등 + `scale(1.04)` 바운스 |
| **4지선다 정답 판정** | `180ms` | 정답 블록 `#DCFCE7` 플립 + 코인 큐브가 아바타 머리 위로 포물선 비행(`260ms`) |
| **오답 / `모르겠어요` 처리** | `160ms` | 붉은 깜빡임 대신 부드러운 모따기 툴팁으로 뜻풀이 제시(학습 스트레스 최소화) |
| **5연승 블록 피버 배너** | `420ms` 인 / `2200ms` 유지 | 방사형 선버스트 회전 + 아바타/타워 동시 점프 하이파이브 + 공속 +50% 오라 |
| **전설 미스터리 큐브 오픈** | `550ms` 크랙 → `240ms` 팝 | 큐브 알 2단 흔들림 후 좌우 껍질 분리 + 무지개 글리치 프레임 등장 |

> **전투 UI 고정 원칙**: 배속(`2배속` 등) 버튼은 학습·방어 리듬 붕괴 방지를 위해 **전면 배제**하고, 하단 퀴즈 패널은 항상 **4지선다 + `모르겠어요`** 5버튼 구성을 유지한다.

## 5. 양산 공정 · 공수 · 위험 관리

### 콘텐츠 양산 목표 (`[20×7=140, 8×12=96, 맵4]`)

| 항목 | 수량 | 제작 파이프라인 | 예상 공수 |
|---|---|---|---|
| **아군 타워 · 아바타 파츠** | `20종 × 7단계 = 140` 파츠/프레임 | 블렌더/MagicaVoxel 공통 큐브 릭(Rig) 1종 기반 색·모자·무기 스왑 + 3/4 아이소메트릭 배치 렌더 → `cwebp -q 85 -alpha_q 100` | 기본 릭 3일 + 20종 양산 7일 (총 10일) |
| **적군 밈 몬스터** | `8종 × 12프레임 = 96` 스프라이트 | 기본 바디 8종 + 4프레임 걷기·4프레임 피격·4프레임 밈 리액션 자동 시트 패킹 | 캐릭터 4일 + 시트 빌드 3일 (총 7일) |
| **전장 맵 타일셋** | `맵 4종` (풀밭·모래섬·설원·무지개성문) | 스터드 잔디/길목/타워패드 모듈러 16타일 재사용, S자 경로와 성문만 교체 | 맵당 1.5일 (총 6일) |

### 주요 위험 및 대응
1. **초5 성인풍/유아풍 이탈 위험**: 너무 유아틱해 보일 수 있으므로 선명한 `181826` 4px 하드 섀도와 "브레인롯 밈 몬스터 + 전설 무지개 등급"으로 트렌디한 로블록스 감성을 유지한다.
2. **가독성 저하 위험**: 전투 배경 채도가 높으므로 상단 HUD와 하단 퀴즈 패널을 불투명 `#FFFDF5` 카드 + `#181826` 3px 테두리로 격리한다.
3. **타워 3단 진화 변별력**: Lv1(단색 우드) → Lv4(시안 다이아+쌍발) → Lv7(황금 날개+무지개 레이저)처럼 실루엣 면적 자체를 단계마다 ~35% 이상 키운다.

## 6. 크롬북(학교 저사양 환경) 성능 예산

- **해상도 & DPR**: 논리 1280×720 고정, `devicePixelRatio` 상한 `1.5` 캡핑 (학교 보급형 크롬북 GPU 필레이트 절약).
- **텍스처 & 메모리**: 전장 1판 기준 아틀라스 2장 이내(`2048×2048` 이하 WebP 85%, 총 VRAM 점유 `< 48 MB`).
- **렌더 & 파티클 상한**: 동시 활성 몬스터 최대 35기, 콘페티/별 큐브 파티클 풀(Object Pool) 최대 60개로 제한하고, 60fps 미달 시 바닥 스터드 스페큘러 광택만 자동 1단계 낮춘다.
- **오프스크린/폰트 최적화**: SVG 아이콘 8종 및 블록 UI는 CSS `box-shadow`와 경량 SVG로 처리해 이미지 디코딩 지연을 없앤다.

### 미생성 원화 (할당량 소진 막힘)
- **`d-enemy-pack`**, **`f1-combo`**, **`f2-reveal`**: `image-generator` 호출 시 모델 할당량 소진 오류(`RESOURCE_EXHAUSTED`, HTTP 429, 약 4시간 22분 후 리셋)가 발생하여 AI 원화 생성이 중단됨.
- **대체 처리**: 목업 완성도 및 1280×720 레이아웃 검증을 위해 `enemy-pack.html`, `dopamine-combo.html`, `dopamine-reveal.html`에는 직접 제작한 N3 복셀 스타일 SVG 아트워크와 기 확보된 에셋(`a-battle-bg.webp`, `b-home-bg.webp`, `c-tower-evo.webp`)을 결합해 7종 전체 캡처를 완료함. 쿼터 리셋 후 동일 프롬프트로 4안씩 생성·선별 교체 가능.
