## 2. 톤 & 팔레트 · UI 규칙

- **아트 화풍**: 2D 애니 셀 셰이딩 + 글로시 하이라이트 (`#131B42` 딥 사파이어 잉크 외곽선, 명도 높고 쨍한 파스텔·비비드 대비).
- **타입별 시그니처 컬러**:
  - **태양 / 빛** (햇살병아리 → 폭풍매 사수 → 태양불사조): `#FFB800` → `#FF6B00`
  - **베리 / 폭발** (베리거북): `#FF4D8D` → `#E11D62`
  - **서리 / 빙결** (서리일각고래): `#00D2FF` → `#2563EB`
  - **은하 / 신비** (은하아홀로틀): `#A855F7` → `#6D28D9`
- **홀로그램 포일 4단계 카드**:
  - `일반 ★`: 실버-슬레이트 (`#CBD5E1` ~ `#94A3B8`)
  - `희귀 ★★`: 스카이-사파이어 (`#BAE6FD` ~ `#6366F1`)
  - `영웅 ★★★`: 골드-아메시스트 (`#FDE047` ~ `#EC4899` ~ `#7C3AED`)
  - `전설 ★★★★`: 무지개 홀로 포일(`linear-gradient(125deg, #FF5E7E, #FFE033, #4EF09D, #3AE2FF, #A855F7, #FF6BE8)`) + 대각선 스윕 광택.

## 4. 손맛(타이밍 · ms 규격)

| 인터랙션 | 지속 시간 (ms) | 이징 / 연출 |
|---|---|---|
| **젤리 버튼 눌림** | `90 ms` (down) / `140 ms` (release) | `translateY(4px)` + 하단 입체 그림자 축소, `cubic-bezier(0.34, 1.56, 0.64, 1)` |
| **전투 카드 슬롯 선택** | `160 ms` | 선택 카드 `translateY(-14px) scale(1.06)` 상승 + 황금 글로우 |
| **퀴즈 정답 / 5연속 하모니** | `120 ms` 히트스톱 → `480 ms` 배너 인 → `650 ms` 원소 빔 | 상단 홀로그램 리본 탄성 등장 + 4원소 빔 수렴 |
| **오답 / `모르겠어요` 힌트** | `220 ms` 흔들림 / `180 ms` 힌트 팝 | 빨간 플래시 대신 라벤더 힌트 하이라이트로 학습 부담 완화 |
| **카드 팩 개봉 (`f2`)** | `320 ms` 지그재그 절개 → `520 ms` 프리즘 폭발 → `280 ms` 카드 플립 | 대각선 포일 스윕 광택 + `NEW!` 스티커 탄성 바운스 |

## 5. 양산 공정 · 공수 · 리스크

### 양산 물량 기준
1. **아군 펫 타워**: `20종 × 7레벨(3단 실루엣 진화 + 오라 강화) = 140장`
2. **밈 적군 & 보스**: `8종 × 12프레임/상태(이동·피격·특수·기절) = 96장`
3. **모험 섬 맵**: `4종` (무지개 초원 섬, 벚꽃 다리 섬, 황금 해변 섬, 크리스털 정원 섬)

### 공정 & 리스크 관리
- **화풍 일관성**: `a-battle-bg` / `b-home-bg` / `c-tower-evo` 와 동일한 2D 애니 셀+광택 시드 프롬프트 + `#131B42` 4~6px 고정 외곽선 가이드.
- **리소스 파이프라인**: 원본 PNG(`asset-source/`) → `cwebp -q 85 -alpha_q 100 -m 6` 자동 WebP 변환(`public/assets/`).
- **리스크**: 카드 4단계 홀로그램 효과를 실시간 WebGL 셰이더로 돌리면 크롬북 GPU 부하 발생 → **정적 WebP 프리즘 텍스처 + CSS `transform`/`opacity` 스윕**으로 대체하여 리스크 제거.

## 6. 크롬북(저사양) 성능 · 용량 예산

- **전용 에셋 실측 용량** (`mock/assets/*.webp`, 총 10개):
  - `a-battle-bg.webp` (121.8 KB), `b-home-bg.webp` (113.0 KB), `c-tower-evo.webp` (111.2 KB)
  - `f1-combo.webp` (109.5 KB), `f2-reveal.webp` (72.1 KB)
  - 크롭 카드 초상 5종(`pet-chick` 17.7 KB, `pet-turtle` 16.8 KB, `pet-narwhal` 15.5 KB, `pet-axolotl` 19.3 KB, `phoenix-reveal` 59.1 KB)
  - **시안 전체 배경+에셋 합계 약 656 KB** — 크롬북 초기 로드 1.5 MB 예산 내 여유 있게 통과.
- **런타임 최적화**:
  - 전투 중 `backdrop-filter: blur()` 사용 최소화(저사양 모드에서 단색 반투명 패널 폴백).
  - 인게임 카드 호버/필살기는 `transform`, `opacity` GPU 합성 속성만 애니메이트(60 fps 방어).

## 7. 4장 비교 선별 기록 & 원화 생성 상태
