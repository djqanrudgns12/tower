## 4. 손맛 (Juice) & 타이밍 명세 (ms)

| 이벤트 | 연출 시퀀스 | 타이밍 (ms) |
|---|---|---|
| **버튼 눌림 (Press/Tap)** | `translateY(4px)` + 하단 압출 그림자 `6px → 2px` 축소 + 탄성 복귀(`cubic-bezier(.34, 1.56, .64, 1)`) | `0 → 80ms` 눌림, `80 → 200ms` 바운스 |
| **퀴즈 정답 & 코인 비행** | 선택지 녹색 플래시 + 버튼 스쿼시(`scale 1.08 → 1.0`) + 코인 6개 베지어 궤적으로 HUD 골드 캡슐 비행 + 카운터 펄스 | `0~120ms` 플래시, `120~420ms` 비행, `420~540ms` 펄스 |
| **5연속 콤보 폭발 (Fever)** | `45ms` 미니 히트스톱 + 화면 `3px` 미세 셰이크 + 상단 기울어진 배너 슬램 + 전 아군 타워 동시 크리티컬 | `0~45ms` 히트스톱, `45~300ms` 슬램, `8,000ms` 피버 지속 |
| **전설 진화 / 해금 세리머니** | 딥네이비 딤(`0.85`) + 상자 흔들림(2회) + 무지개 광선 폭발 + Lv.7 영웅 팝업(`scale 0.4 → 1.08 → 1.0`) | `0~320ms` 흔들림, `320~650ms` 폭발 & 등장 |

## 5. 양산 공정 · 공수 · 위험 관리

### 콘텐츠 목표 물량
- **영웅 타워**: **20종 × 7레벨(또는 핵심 3단 외형 변화) = 140 프레임/포즈 에셋**
- **적군 몬스터**: **8종 × 12프레임(이동 4 + 피격 2 + 사망/개그 4 + 보스 특수 2) = 96 프레임**
- **전장 맵**: **4종** (에메랄드 아레나 · 사탕 계곡 · 별빛 성채 · 용암 스타디움)

### 사전 렌더 파이프라인 (`Tripo 3D → 툰/광택 3D 아틀라스`)
1. **원화 & 3D 생성**: 캐릭터 컨셉 시트 → Tripo 3D(또는 턴테이블 프리렌더)로 2.5등신 베이스 메시 확보.
2. **블렌더 일괄 셰이딩**: 고정 좌상단 림라이트 + 세미 글로시 비닐/금속 셰이더 1회 세팅 후 `3/4 탑다운` 8방향·공격 포즈 배치 렌더링.
3. **WebP 스프라이트 시트 패킹**: `cwebp -q 85 -alpha_q 100 -m 6` 적용, 타워 1종당 `512×512` 아틀라스 1장(`80~140KB` 이내).

### 예상 공수 & 위험 요소
- **공수**: 핵심 파이프라인·셰이더 세팅 3일 + 타워 20종(각 3단 실루엣) 10일 + 적 8종 4일 + 맵 4종 3일 = **약 20인일(1~2인 기준 2~3주)**.
- **위험 & 완화**:
  - *Tripo 메시 일관성 저하*: 1차 레퍼런스 시트에 정면/측면 비율 가이드를 고정하고, 모자·무기 소품은 블렌더 파츠 라이브러리로 결합.
  - *15×9 전장 위 퀴즈 패널 가림*: 전장 하단 24%를 영구 안전 여백(잔디·외곽 보더)으로 설계해 설치 패드 20개가 절대 가려지지 않게 고정.

## 6. 크롬북 60fps 렌더링 예산 (Celeron N4020 / 4GB 기준)

실시간 WebGL 3D 메시를 40~60개씩 돌리지 않고 **사전 렌더된 2D WebP 아틀라스**를 Canvas2D / PixiJS로 합성해 저사양 학교 크롬북에서도 60fps를 유지한다.

| 항목 | 예산 상한 | 구현 전략 |
|---|---|---|
| 동시 드로우콜 | ≤ 120 calls/frame | 텍스처 아틀라스 4장 이내 병합 (전장 1 + 타워 1 + 적군 1 + VFX 1) |
| VRAM 점유 | ≤ 96 MB | 모든 시트 2048×2048 이하 WebP 디코딩(mipmap 비활성) |
| 동시 파티클 | ≤ 80개 | 오브젝트 풀링, 정답 코인·별빛 스파크 재사용 |
| UI 레이어 | DOM(GPU `transform`만 사용) | 상단 HUD·우측 도크·하단 퀴즈 패널은 `will-change` 없이 정적 합성 + 클릭 시 `transform`만 애니메이션 |
| 프레임 예산 | ≤ 11ms / frame (16.6ms 중 여유 5.6ms) | 배속 기능 미제공(고정 1x 시뮬레이션으로 물리 스파이크 원천 차단) |
