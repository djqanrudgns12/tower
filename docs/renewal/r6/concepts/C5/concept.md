# C5 · 팝업 종이 극장 (Layered Papercut Diorama)

> **한 줄 콘셉트**: *Paper Mario*·*Tearaway*·*Lumino City*의 300gsm 색지를 칼로 오려 4~5층으로 쌓은 팝업 그림책 전장, 실제 층간 그림자가 위계를 만드는 독창적 2D 공예 스타일.

---

## 1. 시각 방향 & R5 문제 해결 포인트

- **가장 독창적인 차별화**: 일반 모바일 게임에 흔한 3D/카툰 대신, 손으로 만질 수 있을 듯한 두꺼운 아트 색지(300gsm)와 흰 칼선 단면, 물리적 그림자 깊이로 단번에 시선을 사로잡는다.
- **자동 시각 위계**: 전장 바닥(1층) → 길(2층) → 타워 받침(3층) → 타워·스탠디 몬스터(4~5층)의 종이 그림자 폭만으로도 높낮이와 중요도가 자연스럽게 읽힌다.
- **깔끔한 마감**: 종이 면 자체는 매끈한 파스텔-미드톤 단색이라 작은 글자나 어휘 문제가 위에 얹혀도 시야 방해가 전혀 없다.

## 5. 모션·손맛(Juice) 명세

| 이벤트 | 시각 연출 | 타이밍(ms) | 이징 / 물리 | 음향(SFX) |
|---|---|---|---|---|
| **정답 맞힘** | 선택지 종이 카드가 `2deg` 살짝 들렸다 눌림 + 접힌 색종이 삼각형 8조각 흩날림 | `0 → 440ms` | `easeOutBack` | 종이 카드 '탁!' + 맑은 마림바 |
| **몬스터 처치** | 종이 스탠디가 바닥으로 납작하게 `scaleY(0.1)` 접혀 넘어지며 사선 펄럭 소멸 | `180ms` | `easeInBack` | 가벼운 마분지 '톡!' |
| **타격(피격)** | 스탠디가 `±6deg` 종이처럼 좌우 흔들림 + 밝은 종이 플래시 | `100ms` | 감쇠 진동 | 종이 튕기는 '팅!' |
| **골드 획득** | 금색 호일 종이 동전이 팔랑거리며 상단으로 회전 상승 | `500ms` | 사인파 팔랑임 | 맑은 종소리 |

## 6. 제작 파이프라인 & 양산 공수·비용·위험

- **파이프라인 (순수 2D 레이어드 페이퍼 파츠 + Phaser 멀티레이어 그림자/시차)**:
  1. 각 타워·몬스터를 2D 레이어드 페이퍼 파츠(기본 도형 + `2px` 흰 칼선 테두리 + 미세 종이결 3%)로 제작.
  2. **Blender 또는 Phaser PostFX/멀티레이어 섀도우**로 단면 입체감과 우하단 그림자를 일괄 합성(또는 2.5D 종이 스탠디로 앞/뒤 2면 배치).
  3. 맵 4종은 4~5겹 계단식 등고선 색지 PNG/WebP 레이어를 겹쳐 카메라 미세 이동 시 시차(parallax)가 살아나게 구성.
- **전체 양산 공수 (타워 140 · 몬스터 96 · 맵 4)**:
  - 공용 종이 텍스처·칼선 필터·접힘 이펙트 셰이더/프리셋: **2일**
  - 타워 140개(모듈 색지 파츠 조합): **약 8~9일**
  - 몬스터 96개(스탠디 컷아웃 + 흰 칼선 자동 아웃라인 스크립트): **약 5~6일**
  - 맵 4종(계단식 종이 등고선 + 팝업 랜드마크): **3일**
  - **총 예상**: 약 **18~20일**, 순수 2D 파츠라 수정·대체 비용이 매우 낮음.
- **위험 및 대응**:
  - *위험*: 그림자가 너무 많이 겹치면 전장이 어두워 보일 수 있음. *대응*: 그림자 불투명도를 `rgba(42,51,66,0.18)`로 가볍게 제한하고, 4층 이상의 종이 배경은 밝은 `#F4EFE6`과 `#58A474`를 유지한다.

## 7. 크롬북 성능 예산 & 3~6학년 적합성

- **크롬북 성능 예산**: 순수 2D WebP 스프라이트 + 경량 스탠디 트윈(`scaleY`, `rotation`)만 사용하므로 WebGL 3D나 대용량 스켈레탈 메쉬가 필요 없다. 초기 전송량 **≤ 2.0MB**, `2048×2048` 아틀라스 2장, **고정 60fps**.
- **3~6학년 적합성**: 동화책·만들기 공작과 닮은 따뜻한 감성으로 3~4학년에게 압도적 호감을 얻고, 팝업 메커니즘의 정교함이 5~6학년에게도 세련된 인디 게임처럼 느껴진다.
