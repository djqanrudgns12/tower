## 1. 6종 역할 · 실루엣 차별화 매트릭스

| ID | 이름(가안) | 역할 | Lv20 핵심 실루엣 원칙 (서로 절대 안 겹치게) | 무기 I → IV 변천 |
|---|---|---|---|---|
| `rail` | **레일 포탑** | 단일 고속 | **높고 가는** 수직 경사 레일 첨탑 (좁은 폭, 최장 포신) | 단포신 → 쌍포신 → 삼연장 → 가속 고리 4열 레일 |
| `mortar` | **곡사 포대** | 범위 폭발 | **낮고 넓은** 사각 장갑 포상 (넓은 수평 덩치, 짧고 굵은 포신) | 단일 단포 → 중장갑 포상 → 복열 쌍포 → 다연장 포열 |
| `cryo` | **냉각 중계탑** | 감속·제어 | **중앙 기둥 + 공중 분리 동심원 고리 5단** (층층이 비어 보임) | 3중 링 → 4중 확장 링 → 다중 핀 공명탑 → 5단 분사 고리 |
| `prism` | **프리즘 탑** | 연쇄·관통 | **3/4 부감 삼각 기단 + 속이 뚫린 3축 A프레임 + 부유 앰버 결정** (주 강조색 `#E69F24` 앰버) | 삼각 1수정 → 보조 수정 3기 → 세라믹 아치+이중 수정 → 금테 버팀목+대수정·4위성·왕관 링 |
| `hangar` | **드론 격납고** | 대공·추적 | **발진 레일 육각 갑판 + 우측 격자 마스트 + 직상부 부유 드론 1~4기** (`#E69F24` 유도선·`#B8C0C8` 은회) | 1정찰 드론 → 경사로·2기 → 쌍발 레일·고정익 3기 → 금테·4편대·앰버 지휘기 |
| `bastion` | **방벽 기지** | 지원·근접 | **전면 낮은 곡면 방벽 + 후방 경사 붐 대형 오목 레이더 접시** (절제된 `#2FB5A3` 틸 방벽선 <10% + 금테) | 단판 방벽 → 2단 방벽+소형 접시 → 3분할 세라믹+중형 접시 → 4중 방벽+이중 코어 대형 접시 |

## 2. Blender 부품 키트 7슬롯 · 조립 규격

타워는 `tower-recipes/<id>.json`에서 아래 **7개 슬롯**을 조합해 11단계를 자동 렌더한다.
- 시트 참조: [tower-parts-exploded.webp](file:///Users/bodyking/Desktop/Architecture/towerdeffense/docs/renewal/r6/bible/sheets/tower-parts-exploded.webp) *(R04 분해도·7슬롯 매핑 검수 완료, 짝수 레벨 외곽 돌출 및 밝은 포구·코어 테두리 규약 포함)*

| 슬롯 키 | 역할 | 회전 분리 | 레벨별 증설 규칙 |
|---|---|---|---|
| `base` | 팔각/사각 전술 기단, 지면 접지부 | 고정(0°) | Lv1(기본) → Lv8(코너 앵커) → Lv14(확장 갑판) → Lv20(금테 기단) |
| `body` | 기둥·차체 코어, 구동부 | 고정(또는 일부 회전) | Lv1(단순) → Lv6(유압 실린더) → Lv12(세라믹 하우징) → Lv18(이중 코어) |
| `armor` | 모따기 장갑판, 방벽, 측면 스커트 | 고정/반고정 | **짝수 레벨(2·4·8·10·14·16·20)** 미세 진화의 핵심 슬롯 |
| `turret` | 상부 회전 포두·마운트 | **16방향/자유 회전** | `rail`/`mortar`/`hangar` 포두는 `base+body`와 분리 렌더 |
| `weapon` | 실제 발사체·포신·수정·드론 | 포두 종속 회전 | 무기 단계 I(Lv1) → II(Lv6) → III(Lv12) → IV(Lv18)마다 교체 |
| `deco` | 안테나, 냉각 핀, 레이더 접시, 보조 날개 | 회전/부유 | Lv4·Lv10·Lv16·Lv20마다 보조 장치 1~2개 추가 |
| `mark` | 틸/앰버 계급 띠, 금테 모따기선 | 전체 종속 | 재질 4단계에 따라 선 색상(`#4A5563` → `#B8C0C8` → `#2FB5A3` → `#E69F24`) 변화 |
