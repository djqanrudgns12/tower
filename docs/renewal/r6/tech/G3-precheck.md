# R6 G3 사전 통합 점검

기준은 [R6 PRD](../PRD-r6.md)와 [R04 화면 시안](../round3/concepts/R04/concept.md)이다. 개발 서버에서 초원 고원 전투와 홈을 점검한다.

## 전투 화면과 홈

- 전투 화면은 HUD와 문제판에 실제 높이를 배정한 뒤, 남은 공간에 초원 고원을 투영 비율에 맞춰 배치한다. 낮은 가로 화면에서는 타워 도크가 전장 옆에 오고 문제판이 전체 폭을 쓴다.
- Chromium에서 질문·보기 네 개·모르겠어요의 전체 영역이 네 화면 모두 뷰포트 안에 들어왔다. 844×390에서는 터치 입력을 켰다.
- 홈은 `715016b4`에서 연결한 `assets/r6/map/meadow-plateau.webp`를 사용한다. Chromium에서 해당 파일이 로드되고 디코딩된 것을 확인했다.

| 화면 | 전장 | 질문 / 보기 | 문서 스크롤 | 캡처 |
| --- | --- | --- | --- | --- |
| 1280×720 | 731×457 | 20 / 16px | 0px | `1280x720.webp` |
| 1366×768 | 820×513 | 20 / 16px | 0px | `1366x768.webp` |
| 1366×650 | 512×320 | 20 / 16px | 0px | `1366x650.webp` |
| 844×390 | 259×162 | 16 / 16px | 0px | `844x390.webp` |

캡처는 `test-results/r6-g3-captures/`에 있다. 전장 설치대 영역의 카메라 점유율은 가로 92.77~92.86%, 세로 90.02%였다.

## 보통 난이도 통주

3학년 문제은행, 초원 고원, 시드 1로 새 판을 생성한다. 봇은 5문제 중 4문제를 맞히고 1문제를 틀리며, 기존 시뮬레이터의 가성비 전략으로 타워를 짓고 강화한다. 15웨이브를 지키면 판을 끝낸다. 실시간 브라우저 시험은 정상 속도의 논리 틱과 Phaser 렌더 완료 횟수를 측정하고, 결과 화면의 저장 표시와 IndexedDB 기록을 검사한다.

시뮬레이터는 같은 난이도와 시드에서 15웨이브에 도달했다. 균형형 봇의 평균 웨이브 시간은 0.85분이었다.

첫 브라우저 계측은 W3 전투 중 자동 일시정지로 끝났다. W2까지 지켰고 152.7초 동안 16.36fps를 기록했다. 오류 269건은 모두 R6 발사음 악보가 비어 있어 발생한 예외였다. 레일·냉각·프리즘·드론·방벽의 효과음을 추가하고 R6 타워 6종의 발사 이벤트를 단위 시험에 넣었다. 경고 4건은 Chromium WebGL의 `ReadPixels` 지연이었다. 이후 통주에서는 계측 부하를 줄이기 위해 프레임 캡처를 끄고 렌더 완료 이벤트로 FPS를 센다.

발사음 수정 후 헤드리스 Chromium 계측은 W9까지 지켰다. 419.2초, 평균 58.40fps, 정답 92개와 오답 23개(80.0%), 오류 0건, `ReadPixels` 경고 4건이었다. W1~3의 2종족·T1, W4~6의 3종족·T1~T2, W7~9의 4종족·T2~T3을 확인했다. W5 기계 군단 보스가 화면에 그려졌고 W3·6·9 뒤에 프리즘 탑·드론 격납고·방벽 기지가 해금됐다. 레일 포탑의 11형태가 모두 그려졌으며 무기 II·III·IV 전환을 확인했다. 곡사 포대와 냉각 중계탑은 당시 매니페스트에서 임시 표시였다.

이 계측은 학생 접속으로 프로세스 우선순위가 낮아진 뒤 W10에서 `PERFORMANCE` 자동 정지 3회로 끝났다. 두 번은 계속하기로 재개했다. 원본은 `test-results/r6-g3-run/`의 `run.json`과 추적 파일에 있다.

1366×650에서 Apple Metal로 바꿔 실행했을 때는 학생 접속과 우선순위 변경 후 W3 전투에서 중단됐다. W2까지 완료했고 150.2초, 평균 15.48fps, 오류·경고 0건이었다. 자동 정지 뒤 12번 재개했다. 원본은 `test-results/r6-g3-metal/`에 있다.

### W15 완료 결과

844×390, Mac mini의 Chromium과 Apple Metal 렌더러에서 W1~W15를 모두 지켰다. 시작 시 운영 학생 접속은 20명이었고 시험은 자원 보호 도구의 낮은 우선순위로 실행됐다.

| 항목 | 관측 결과 |
| --- | --- |
| 판 시간과 속도 | 실제 815.3초, 게임 틱 기준 636.5초, 정지를 포함한 평균 7.05fps |
| 정답률 | 134정답 / 33오답, 80.2% |
| 오류·경고 | 0건·0건 |
| 웨이브 혼합 | W1~3 2종족·T1, W4~6 3종족·T1~T2, W7~10 4종족·T2~T3, W11~15 5종족·T2~T3 |
| 보스 표시 | W5 기계 군단 T1, W10 바위 거인 T2, W15 군체 벌레 T3 |
| 해금 | W3 프리즘 탑, W6 드론 격납고, W9 방벽 기지 |
| 형태·무기 | 레일 포탑 Lv1~20의 11형태와 무기 I~IV, 곡사 포대와 냉각 중계탑의 Lv1·2·4·6 형태와 무기 II. 이 판에서 관측한 원화 33건 중 누락 0건 |
| 결과와 저장 | W15 뒤 종료. 결과 화면에서 ‘기록 저장됨’ 표시와 IndexedDB의 보통 난이도 R6 기록 확인 |
| 자동 정지 | `PERFORMANCE` 95회. 매번 계속하기로 재개했다. 통주 e2e는 무정지 단언에서 실패했다. |

원본은 `test-results/r6-g3-landscape-run/`의 `run.json`과 추적 파일에 있다. 실기기 크롬북과 프로젝터 확인은 미실행이다.

## 검사

- 범위 단위 시험 21개, 발사음 단위 시험 13개 통과
- 화면 4개·홈 에셋·전장 감속·이전 계약 e2e 통과. 설치대 시험은 로딩이 끝나고 실제 전장 카메라가 그려진 뒤 픽셀을 읽도록 바꾼 후 통과
- `npm run verify` 통과. 전체 단위 시험 1,846개, 계획 검사 49개, 콘텐츠 검사 604개를 통과했고 위키 검사에서 경고 7건이 있었다.
