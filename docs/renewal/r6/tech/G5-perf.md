# R6 저사양 전장 점검

## 품질 조절과 정지 조건

기존에는 프레임 간격 250ms 초과가 5초 안에 세 번 발생하거나, 프레임당 최대 5틱을 처리한 뒤에도 밀린 시간이 250ms를 넘으면 자동으로 멈췄다. 고정 FPS 조건은 없었다.

R6는 진행 중인 전경 프레임을 5초씩 모은다. 평균 30fps 미만이면 한 단계 낮추고, 45fps 이상을 20초 연속 유지하면 한 단계 올린다.

| 단계 | 렌더링 동작 |
| --- | --- |
| 0 | 기본 화질. 고해상도 화면에서는 타워 시트 384px 사용 |
| 1 | 기본 192px 타워 시트 사용. 연기·먼지와 일반 비행 적 그림자 생략 |
| 2 | 성문에서 6칸 넘게 남은 적의 Spine 자세는 100ms, 가까운 적은 50ms마다 갱신. 보스 자세와 적 위치는 매 프레임 갱신. 배경 움직임과 지면 전환 효과 생략 |
| 3 | 캔버스 내부 가로·세로 해상도를 각각 0.75배로 렌더링. 화면에 표시되는 크기 유지 |

3단계에서 평균 15fps 미만인 구간이 10초 연속 이어지면 멈춘다. “기기가 느려서 잠시 멈췄어요. 계속하기를 누르세요.”라는 문구를 보여 주고 학생이 계속하기를 누르면 같은 품질에서 다시 측정한다. 설정의 ‘가벼운 화면’은 선택 즉시 3단계를 적용하며 기기에 저장된다. 기존 v1 판은 기존 정지 조건을 사용한다.

논리는 30Hz 고정 틱과 프레임당 5틱 상한을 사용한다. 250ms 초과 단일 끊김은 기존처럼 경과 시간을 따라잡지 않는다. 단위 시험은 같은 초기 상태와 경과 시간으로 50fps와 20fps에서 각각 450틱을 실행해 상태와 피격 등 도메인 사건이 일치함을 확인한다.

R6의 React 화면은 질문, 남은 적 수 등 표시값이 바뀐 틱에 갱신한다. 화면 크기나 확대 대상이 같으면 Phaser 카메라 배치도 다시 계산하지 않는다.

## W1~W10 재현

학생 접속 수와 자원 입장 가능 여부를 확인한 뒤 실행한다. 로컬 개발 서버와 시험 브라우저에서 3학년·보통 난이도·시드 1로 진행한다. 봇은 다섯 문제 중 네 문제를 맞히고 보상 골드로 타워를 설치·강화한다.

```sh
/Users/bodyking/.local/bin/resource-guard status --profile avatar
E2E_PORT=5197 VITE_API_BASE='' \
  /Users/bodyking/.local/bin/resource-guard run --profile test --wait-seconds 900 -- \
  npm run test:r6-perf -- --output="test-results/r6-g5-perf-$(date +%Y%m%d-%H%M%S)"
```

기본 명령은 설정 전환 확인 후 CPU 6배 감속과 1배 기준선을 차례로 실행한다. 6배만 측정하려면 끝에 `--grep 'CPU 6배'`를 붙인다. CPU 감속은 Chromium CDP로 적용하며 GPU와 실기기 발열은 재현 범위 밖이다.

각 통주의 `run.json`에 렌더 완료 횟수로 계산한 평균 FPS, 품질 전환 시각과 웨이브, 자동 정지 횟수, 오류가 남는다. W10 완주와 자동 정지 0회를 검사한다. 자원 보호 도구가 낮은 우선순위를 적용하면 시작·변경 로그를 기록하고 학생 접속 0명일 때 최대 두 번까지만 다시 측정한다.

## 측정 결과

헤드리스 Chromium, Apple Metal, 844×390에서 측정했다. 첫 실행은 학생 1명 접속 중 시작해 `utility` 우선순위 상한이 걸렸다. 접속이 0명으로 바뀐 뒤에도 이 실행의 상한은 유지됐다.

| 초기 측정 · 낮은 우선순위 | 도달 | 평균 FPS | 품질 전환 | 자동 정지 |
| --- | --- | --- | --- | --- |
| CPU 6배 | W1 완료, W2 중단 | 13.89 | 0 → 1 → 2 → 3 | 4회 |
| CPU 1배 | W1 완료, W2 중단 | 13.68 | 0 → 1 → 2 → 3 | 4회 |

첫 측정은 네 번째 정지에서 끝냈다. 이후 표시값이 같은 틱의 React 갱신과 같은 조건의 카메라 재배치를 줄이고, 학생 접속 0명일 때 다시 실행했다. 첫 측정 자료는 `test-results/r6-g5-perf/`의 각 `run.json`에 있다.

| 재측정 · 일반 우선순위에서 시작 | 도달 | 경과 | 평균 FPS | 품질 전환 | 자동 정지 |
| --- | --- | --- | --- | --- | --- |
| CPU 6배 | W10 완료 | 443.4초 | 59.49 | 0 유지 | 0회 |
| CPU 1배 · W5에서 낮은 우선순위로 변경 | W5 완료, W6 중단 | 262.2초 | 48.20 | W5에서 0 → 1 → 2 → 3 | 4회 |
| CPU 1배 · 마지막 재측정 | W10 완료 | 443.3초 | 59.96 | 0 유지 | 0회 |

재측정 자료는 `test-results/r6-g5-perf-retry/`와 `test-results/r6-g5-perf-baseline/`의 각 `run.json`에 있다. 첫 측정과 재측정 사이에는 코드와 우선순위가 함께 바뀌었다. 일반 우선순위에서 완료한 두 실행의 브라우저 오류는 0건이었다. 단계 전환은 우선순위가 내려간 CPU 1배 측정과 별도 단위 시험에서 확인했고, 고해상도 브라우저에서 192px↔384px 전환을 확인했다. 실제 크롬북과 프로젝터 확인은 미실행이다.

## W20 통주

G5 통합 기준(CPU 6배 감속에서 W20 완주, 자동 정지 0회, 평균 50fps 이상)을 검증하기 위해 `tests/e2e/r6-perf.spec.ts`에 `W1~W20` 통주와 1초 창 최저 FPS, 웨이브별 최대 동시 적 수, 보스 등장 기록을 추가하고 학생 접속 0명·일반 우선순위에서 실행했다(기준 커밋 `d78e9563`).

```sh
E2E_PORT=5197 VITE_API_BASE='' \
  /Users/bodyking/.local/bin/resource-guard run --profile test --wait-seconds 1800 -- \
  npm run test:r6-perf -- --grep 'CPU 6배 · W1~W20' --output="test-results/r6-g5-perf-w20-cpu6"

E2E_PORT=5197 VITE_API_BASE='' \
  /Users/bodyking/.local/bin/resource-guard run --profile test --wait-seconds 1800 -- \
  npm run test:r6-perf -- --grep 'CPU 1배 · W1~W20' --output="test-results/r6-g5-perf-w20-cpu1"
```

- **환경**: 헤드리스 Chromium, Apple M6 (ANGLE Metal), 844×390, 3학년·보통 난이도·시드 1(성문 15/15 유지), W1~W20(W5 `machine-boss-t1` · W10 `stone-boss-t2` · W15 `insect-boss-t3` · W20 `elf-boss-t4` 포함).

| 조건 · 일반 우선순위 | 도달 | 경과 | 평균 FPS | 최저 구간 FPS (1초 창) | 최대 동시 적 | 품질 전환 | 자동 정지 | 오류 |
| --- | --- | ---: | ---: | --- | ---: | --- | ---: | ---: |
| CPU 6배 | W20 완료 | 905.0초 | 59.35 | 50.97fps (W6 · 적 1) | 22 (W19) · 20 (W20) | 0 유지 | 0회 | 0건 |
| CPU 1배 | W20 완료 | 904.8초 | 59.98 | 56.95fps (W15 · 적 1) | 22 (W19) · 20 (W20) | 0 유지 | 0회 | 0건 |

- **판정**: CPU 6배·1배 모두 W20 완주, 자동 정지 0회, 평균 FPS 59.35 / 59.98로 기준(평균 50fps 이상 · 자동 정지 0회)을 통과했다. W15(`insect-boss-t3`, 최대 동시 적 14, 최저 1초 55.45fps / 56.95fps)와 W20(`elf-boss-t4`, 최대 동시 적 20, 최저 1초 56.91fps / 59.06fps) 밀집 구간에서도 품질 하향 없이 55fps 이상을 유지했다.
- **기록 위치**: `test-results/r6-g5-perf-w20-cpu6/` 및 `test-results/r6-g5-perf-w20-cpu1/`의 각 `run.json`(git 무시 경로). 실제 학교 크롬북(1366×768) 및 교실 프로젝터 실기기는 미실행이다.
