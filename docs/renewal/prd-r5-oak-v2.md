## 0. 사용자 결정(2026-11-04)

1. **디자인은 나무 창으로 통일한다.** 홈·전투·모든 창(새 게임·설정·설명서·랭킹·일시정지·결과·오답 노트)이 같은 재질을 쓴다.
2. **학습 피드백과 디테일까지 고도화한다.** 서브에이전트·세션으로 나눠 하되 차질이 없게 총괄이 세부까지 챙긴다.
3. **용어는 평이하고 널리 쓰는 말로 쓴다.** 예: 랭킹 점수, 시작. 세계관 말투(수호·출정·징집·작전실 등)는 쓰지 않는다.
4. **글자 크기 설정의 범위는 총괄이 정한다**(§3.4).
5. 제안 4가지에 대한 결정:
   - **정체성은 이전 것으로**: 참나무·양피지·놋쇠 재질, 정보가 충분히 보이는 구성.
   - **구조는 R4 것으로**: 그 위에, R4에서 빠지거나 훼손된 것을 이전 UI/UX를 참고해 다시 짓는다.
   - **재질은 그림(원화 질감)으로 고도화한다.**
   - **한 번에 통일한다**: 공용 부품에 재질을 입혀 모든 화면을 같이 바꾼다.
6. 운용: 여러 세션과 서브에이전트를 쓴다. Claude와 Antigravity를 쓰고, Codex는 토큰이 부족해 이번에는 쓰지 않는다. 한 번에 다 하지 않고 단계로 나눈다.

## 1. 원칙

- **정체성 = 이전, 뼈대 = R4.** 키캡·카드 전체 버튼·큰 숫자 위계·접근성·하한 같은 R4 구조는 유지한다. 그 위에 이전 디자인의 재질과 정보 밀도, 학습 피드백을 되살린다.
- **흉내가 아니라 그림.** R4가 지적한 진짜 문제는 "갈색 CSS 상자가 나무를 흉내 낸 것"이었다. 틀·판·면은 41번 화풍의 원화 질감(9-slice)으로 그리고, 글이 놓이는 면만 단색 양피지로 둔다.
- **부품에서 한 번에.** 화면마다 재질을 따로 칠하지 않는다. `src/ui/kit`(Button·IconButton·Card·Segmented·Toggle·Stat·Badge·Modal·ArtIcon)과 전역 토큰에 재질을 입히면 모든 화면이 함께 바뀐다. 화면 코드는 배치와 기능만 맡는다.
- **잃은 학습 피드백을 되살리고, 숨은 신기능을 화면에 연결한다.** 연속 정답 보너스·복습 표시·오답 이유는 데이터가 있는데 화면에 없다(§5).
- **기능을 잃지 않는다.** R4 이후 생긴 기능(§4)은 모두 유지한다. 지우는 것은 사용자 확인 뒤에만 한다.
- **수치 관문을 유지한다.** 글자 13px·누름 44px 하한, 가로 넘침 0, 1366×650에서 홈·전투 스크롤 없음, 움직임 줄이기, axe 0, 60fps(CPU 4배 감속).
- **단일 폴더.** 모든 세션이 이 폴더에서 일하고, 파일 소유를 나누고, 자기 경로만 커밋한다(§7).

## 3. 디자인 체계 v4(참나무 작전실 v2)

P0에서 `docs/renewal/ui-rules-v4.md`로 확정한다. 아래는 그 뼈대다.

### 3.1 재질 4단

| 재질 | 쓰는 곳 | 구현 |
|---|---|---|
| 호두나무 틀(짙음) | 화면 바깥 틀, 전장 틀, 머리판, 창 테 | 원화 9-slice(`border-image`) |
| 참나무 판(중간) | 옆판(타워 칸·상황 카드), 하단 문제판 바탕, 탭 줄 | 원화 타일 |
| 양피지 면(밝음) | 글·문제·보기·카드 본문 | 단색 양피지 + 가장자리만 원화 |
| 놋쇠 | 한 화면의 "지금 누를 것" 하나(전투 시작·새 게임 등), 강조 배지 | 원화 판 + 단색 글자 |

- 그라데이션·블러·글자 그림자 금지(v3 규정 유지). 깊이는 원화 질감과 단단한 바닥 그림자(0 2~4px)로만 낸다.
- 색 토큰은 `global.css` 한 곳에 둔다. 지금 `home.module.css`의 `.lobbyRoot` 안에만 있는 옛 토큰을 공식 토큰으로 올리고, v3 이름(`--bg`·`--paper`·`--line`·`--ink`·`--green`·`--amber`·`--red`)은 참나무 값으로 다시 매핑한다. 그러면 R4 부품이 그대로 따라온다.
- 그림 무게 예산: 재질 원화 전체 400KB 이하(webp). 9-slice는 한 장당 512px 이하.

## 4. R4 이후 생긴 것(모두 유지)

- **부품·아이콘**: kit 9종, 조작 아이콘 12종, 원화 아이콘 28장(상태 8·적 특성 8·보물 12), 지도 썸네일 4장.
- **전투**
  - 답안 키캡 2×2와 '모르겠어요' 키, 카드 전체가 버튼인 ChoiceCard
  - 잘 잡는 적·약한 적 아이콘, 상황 카드(다음 웨이브 적 초상화 × 수 + 특성 아이콘, 대응 공백 경고, 남은 적)
  - 잠긴 칸 + 호박 링, 최고 기록 줄, 보물 줄·보물 창
  - 적 특성 배지, 땅굴 반투명, 피격 점멸, 보스 띠의 종족 보스 초상화
  - 폰 풀블리드 배치, 준비 바의 첫 3웨이브 힌트
- **학습**: 도움 단계(난이도 자동 조절, 화면 비표시가 설계), 오답 노트(졸업 ●○, 홈 배지·결과 연결), 복습 문제 재출제.
- **결과**: 큰 웨이브 숫자, 새 최고 기록·아까운 패배 문구, 이전 최고, 노트 변화, 낱말 카드 펼침.
- **설명서**: 큰 그림 카드, '자세히', 타워 상성 카드.
- **새 게임**: 학년 자물쇠 + 막힌 이유 한 줄, 실제 지도 썸네일·이름, 고른 난이도 설명 한 줄.
- **설정**: 기록 지우기가 오답 노트도 지움. 정지 화면 Segmented·Toggle.
- **접근성**: 첫 포커스 = 내용 첫 요소, roving tabindex, Segmented가 막힌 칸을 건너뜀, 수직선 0.0px 잠금, 제출 흔들림 0.
- **이어하기 제거**(3b9951f): 되살리지 않는다.

### 7.2 커밋·충돌 규칙
- 시작 전 `git status`를 본다. 내 소유 경로에 남의 미커밋 변경이 있으면 멈추고 메인에 보고한다.
- 커밋은 `git commit --only -- <내 경로>`로만 한다. `git add -A`·`stash`·`reset`·`checkout -- .`·`clean`은 쓰지 않는다.
- 커밋 전 `npx tsc --noEmit -p tsconfig.json`이 통과해야 한다. 다른 세션 때문에 깨지면 메인에 보고한다.
- push는 메인만 한다(단계 관문 뒤).

### 7.3 검사 예산(verification-budget)
- 작업 중에는 자기 범위의 시험만 돌린다.
  - 단위: `npx vitest run <내 시험>`
  - e2e: `E2E_PORT=<세션별> npx playwright test <내 spec> --output test-results/e2e-<세션>`
  - 포트: K 5401 · A 5411 · B 5421 · C 5431
- 전체 verify·e2e는 메인이 단계 관문에서 한 번만 돌린다.
- 같은 실패가 3번이면 멈추고 시도·가설·증거를 보고한다. 기대값을 바꿔 통과시키지 않는다.

| Codex | 이번 R5에서는 쓰지 않는다(토큰 부족) | 회복되면 P4 독립 코드 검토만 |
