## 목표

정원 맵(`garden_u`, `docs/contracts/maps.candidate.v0.4.json`)을 41번 원화(`docs/assets/design-41-kingdom-expedition.png`)의 자연스러움까지 끌어올릴 그림 재료를 만든다. 화풍은 그대로다. 기준은 `docs/renewal/art-bible-v2.md`이고, 특히 §1(지금 인공적으로 보이는 이유)·§2(레이어)·§5(반려 기준)를 지켜라.

지금 맵의 문제: 회색 받침 20개가 주인공이 됨, 풀 한 장 반복 + 격자 난수 덤불, 맵 끝이 잘린 판, 균일한 길 띠, 높낮이·물·사람 흔적 없음. 기존 ART-002의 풀은 일부러 아주 평평하게 만들었는데, 그게 단조로움의 원인 중 하나다. 이번에는 **낮은 대비를 지키면서 자연스러운 큰 덩어리 변화**가 있어야 한다.

참조 이미지: 41번 원화, `asset-source/incoming/ART-SAMPLE-001/contact-sheet.png`, `asset-source/incoming/ART-003/contact-sheet.png`, `public/assets/deco.tree.r1.png`, `public/assets/deco.stele.r1.png`. 생성 방식·처리 스크립트·기록 형식은 `asset-source/incoming/ART-002/`를 따른다(prompts.json, sources/, manifest.json, 검사 로그, 접촉판).

## 처리와 미리보기 (중요)

1. 생성 → 다듬기(잘라내기·크기·알파 검사) → `manifest.json`(기존 형식, status는 전부 `draft`).
2. 접촉판: 32/48/64px 축소판과 밝은·어두운 배경 두 장.
3. **합성 미리보기**: 스크립트로 `garden_u`를 1920×1152(칸 128px)로 합성한다. 길 중심선은 `pathCells`를 둥근 이음으로 잇고, 받침은 `slots`, 장식 칸은 `decorations`를 쓴다. 소품·가장자리 숲·얼룩의 위치는 네가 **손으로 정한 배치표** `garden_u.layout.json`(id, x, y, 칸 단위 실수, 크기 배율, 좌우반전)로 둔다. 격자 난수 흩뿌리기 금지, 3~5개씩 무리 짓기. 설치 자리·길을 가리면 안 된다. 기존 타워 그림 3개(궁수·포탑·서리)를 받침 몇 곳에 올린 버전과 빈 버전 두 장을 만든다.
4. `PROGRESS.md`에 항목별 상태, 반려하고 다시 만든 것과 이유, 남은 문제를 적는다.
