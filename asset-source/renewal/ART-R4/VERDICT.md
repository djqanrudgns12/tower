# ART-R4 판정 (2026-10-31, 총괄)

Codex 실행은 마지막 정리 단계에서 실패 코드로 끝났지만 본체 10·무기 층 5(sling·ballista·mortar·hwacha·wind 날개)·로스터 접촉판이 처리돼 있어 총괄이 판정했다.

- 형태·시점: 통과. 20종을 나란히 놓아도 같은 게임으로 보인다(상부 사선, 강돌 받침, 소나무·무쇠 재료).
- 보완 필요(색 표식): 신규 10종이 대부분 갈색 나무색이라 48·32px에서 서로 비슷하게 뭉친다. 기존 10종은 초록 지붕·보라 지붕·파란 수정·붉은 돔·파란 깃발처럼 **역할 색 표식**이 있다. 신규도 각자 고유 강조색 면 하나를 더한다(Antigravity 편집으로 처리, 형태·시점 유지).
- falcon: 기둥이 가늘어 실루엣이 약하다. 횃대 기단을 넓히고 매를 조금 키운다.
- alchemist(청록 약병)·wind(크림 날개)는 이미 색 표식이 있어 그대로 둔다.
